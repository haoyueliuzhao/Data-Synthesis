## 3. 后继规则 public_task_target_binding.v2

### 3.1 局部关系与原任务适用性分离

分别记录 local_relation_validity、public_task_applicability、
public_scope_match、registered_scope_match_diagnostic_only，以及实际 Final 依赖链
是否完成公开请求。模型自述目标不是原任务的替代物。

局部公式可以正确但不适用于所问期间或物理量。私有登记匹配只作单列诊断，
不能将 PUBLIC_UNDERSPECIFIED 或 NEED_SOURCE_CHECK 自动填成 PASS。
明确违反所有相关公开解释的对象或完成链仍可记录 FAIL，而不被另一未定轴掩盖。
公开任务清楚但私有登记直接错误时，可独立核对公开任务适用性；旧参考仍不能进入
后继主成绩，必须先另立正确的任务/参考版本。

不要求每个中间结果直接等于最终目标。例如先计算有符号净资产贡献，再完成所问
正金额的合法转换，可以是完整链；只完成中间物理量而直接终止则不能替代目标。
本轮不改数量容差、Final 提取、符号解析、单位词元或计算器实现。

### 3.2 来源字段承担何种声明

真实公共合同明确规定 arguments.variables 的每个变量名可映射到数值，
或嵌套的 {value, source, unit}，或既有 result_id；另有 arguments.sources，
用于变量名到来源 ID 的关联声明。它未将扁平 variables.value/source/unit
定义为一个源值断言对象。

| 来源语义 | 核对对象 |
| --- | --- |
| DIRECT_SOURCE_VALUE | 明确声称来源直接记录该输入值，核对事实值与对象/期间 |
| DERIVED_FROM_SOURCES | 声称该值由来源和关系导出，核对推导支持，不要求单元格等于结果 |
| GENERAL_REFERENCE | 普通相关引用，核对其相关性，不自动扩展成源值等式 |
| UNRESOLVED | 合同和周围文字不足以唯一确定声明角色，保留未定 |

未消费字段可能仍是当前错误声明，不因未参与算式而消失；但字段相邻也不能自动
认证一条直接源值断言。撤回旧错误须有实际公开纠正或明确替代证据，不能因为出现
后来正确答案就抹掉旧记录。历史错误及其是否仍有效分别记录。

没有新增 numeric-ID-only、统一 JSON 模板、强制来源列表完整或某条指定公式门槛。
本规则是测量规则，未改旧 Harness，也未向模型新增提示。

## 5. 旧 252 条的派生失败结构

七维为 quantity、formula、source、unit、publication、execution、Final。
前五维直接使用原数量状态及原对应语义子项；execution 只表示是否存在真实成功
calculate（缺失为该条件 FAIL，不推断原因）；Final 保留原一致性状态并禁止无 Final
时成为 PASS，原交付状态另列。

七维不假装包含全部原资格门。调用前/同调用证据、计算量解释、工具结果与发布量
一致、显式 Final.result_id 对应、选中成功计算及实际 Final 金额检查等布尔条件，
均作为原始剩余门单列。只核对保存门的布尔组合与原完整 PASS 投影是否一致，
不重新运行旧财务资格器，不重新判断 1,260 项语义。

| 互斥分类 | 定义 |
| --- | --- |
| ALL_SEVEN_PASS | 七维都 PASS；还需单看原技术剩余门 |
| ONLY_ONE_FAIL | 恰一项 FAIL，且没有未知 |
| MULTIPLE_FAIL | 至少两项 FAIL，且没有未知 |
| INFORMATION_INSUFFICIENT | 至少一项原未知/未建立；同时存在的已知 FAIL 仍另列 |

保存每条向量、精确联合模式、两两未通过交集及唯一未通过条件；按阶段、任务、
种子、分布臂、臂×组和具体模型分别汇总。跨种子和同题不是独立任务。
调用数仍与会话数区分，不将 434/599 的旧调用错误比例当成会话失败率。

这些统计说明保存的评分条件如何共同未成立，不表示模型失效的唯一原因，
不证明工具错误掩盖了来源类效应，也不等于修复某环节后的因果效用。
如列 C04 单条翻转的分数，只是“其他所有旧指示不变”的显式假设：
20/72 对 20/72，仍无正收益，不是本轮实测重评分。
