该包质量/该包全部目标 Token 数，不追加行均值或全局 Token 均值。

同一个参数状态下，L_plus−L_0=(mean_A−mean_D)/36；
L_minus−L_0=−(mean_A−mean_D)/36。该恒等式是局部权重接线检查，
