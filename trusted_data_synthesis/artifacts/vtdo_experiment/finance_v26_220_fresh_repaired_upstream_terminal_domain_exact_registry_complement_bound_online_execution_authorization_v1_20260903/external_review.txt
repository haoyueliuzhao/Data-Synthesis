### Scope limitation

第一，A1 是“**精确 v26.218 实现源码的 detached rebuild，读取 canonical repository 中已冻结的 evidence parents**”，不是完整依赖环境、操作系统和整个仓库的 hermetic rebuild。报告已经明确说明 canonical repository 只作为 frozen evidence root，因此没有构成措辞欺骗。

### Future hardening

v26.217 历史实现仍存在 `id(error)` 依赖对象地址的生命周期问题：在一个大型单进程 adjacent test run 中，v26.217 的八个测试会因地址复用而在 fixture setup 停止；独立进程执行则为 `8/8`。v26.219 已如实区分单进程结果和进程隔离结果，没有把它误报为统一的 `89/89` 单进程通过。

这是历史 v26.217 的可维护性问题。它已由 v26.218 的窄 lifetime adapter 隔离，不是 v26.219 Registry-complement 独立审计的 Blocking defect，也不应因此再开启一轮强制修订。
