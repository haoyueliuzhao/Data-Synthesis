# 一、本轮审计结论

**本轮可以按 `PASS_AS_SCOPED` 收口。没有发现直接推翻本轮限定声明的阻断性反例，也没有必须修改历史评分或重跑实验的理由。**

但通过的是：**固定最终模型上的共同目标测量、原 L1 自主行为诊断，以及相应的有限结论**；不是“明细方法已经学会”“类概率已经改变”或“VTDO 已产生训练收益”。本轮原本声明的问题确实限定在这两个诊断对象上。

本次我读取了完整附件，并对公开公式、数表分解和工作量做了独立计算；没有读取冻结仓库、逐 Token 工件、完整参数摘要或 wrapper 源码。因此，下述判断属于**报告审阅与数理核对**，不冒充源码和运行工件的独立复验。

| 审计事项                          | 结论                             |
| ----------------------------- | ------------------------------ |
| 本轮声明是否与实际报告的测量对象一致            | 一致                             |
| 公开数表、权重恒等式和分项归约是否存在直接矛盾       | 未发现                            |
| 是否把算术执行成功冒充完整有效轨迹             | 没有，五条来源冲突被保留为失败                |

## 1. 数学测量成立，但它测到的不是理论 Contribution

为避免与理论中的 \(C_t\) 混淆，以下将报告中的 \(C\) 记为：

$$
C_{\mathrm{fit}}(\theta)
=
\ell_\theta(R03)
-\frac{\ell_\theta(D01)+\ell_\theta(D04)}{2}.
$$

这是**固定三个原样监督包的平均 Token NLL 对比**。报告保留了原包归一化、共同参考目标和相同原始 Token 数组，没有通过比较两臂各自不同的训练目标来判断哪个模型更好。

沿用父实验的质量变化：

$$
\Delta w_{D01}=\Delta w_{D04}=-\frac1{72},
\qquad
\Delta w_{R03}=\frac1{36},
$$

因此，对**同一个模型参数**有：

$$
\begin{aligned}
\mathcal L_Q(\theta)-\mathcal L_P(\theta)
&=
\frac1{36}\ell_\theta(R03)
-\frac1{72}\ell_\theta(D01)
-\frac1{72}\ell_\theta(D04)\\
&=\frac{C_{\mathrm{fit}}(\theta)}{36}.
\end{aligned}
$$

这个恒等式确实成立。它验证的是当前共同目标的归约关系，**不是重新验证一次训练有效性，更不是证明 \(C_{\mathrm{fit}}\) 等于边际训练价值**。

报告中的三个配对分解也能够直接核对：

| 种子 |      R 包损失变化 |   D 两包平均损失变化 | 两者之差，即 \(\Delta C_{\mathrm{fit}}\) |
| -- | -----------: | -----------: | ---------------------------------: |
| 11 | −0.006566011 | +0.003414678 |                       −0.009980689 |
| 29 | −0.003061616 | +0.008205108 |                       −0.011266724 |
| 47 | −0.002750665 | +0.004270659 |                       −0.007021324 |

calculate 和 Final 按原整包长度归一化后的两个贡献，也分别能相加还原每个种子的整包差值。**这里没有把不同长度的分项均值直接等权平均，也没有隐去 D 的拟合退让。**

精度边界需要保持：报告给出的完整工件归约误差为 \(1.0495\times10^{-16}\)，但正文数表只显示九位小数。我用显示值复算得到的残差与舍入精度相容，**不能据此声称独立复现了工件级 \(10^{-16}\) 结果**；也不能反过来把显示舍入造成的误差判成实现失败。

### 这一结果究竟说明什么？

它说明：在已报告的配对条件下，**改变固定有限支持上的类质量，确实伴随了预期方向的相对拟合响应**。

它不说明：

* Q 的整体拟合一定更好。两个共同总体目标只在种子 11 上降低，29、47 上都略有上升。
* calculate 分项的改善就是孤立的数学方法改善。该文本仍包含变量命名、来源标注、自然语言和 JSON。
* 负的 \(C_{\mathrm{fit}}\) 就是新学得的明细偏好。B0 的这个量本来已经为负。

因此，报告当前的解释尺度是合适的。

## 2. 行为诊断没有把“算对”提升成“轨迹有效”

本轮最值得保留的区分是：

$$
\text{实际执行 }134-116=18
\quad\neq\quad
\text{有效执行了余额差解决行为}.
$$

五个模型明确将：

$$
134\rightarrow \texttt{source:t4c1n0},
\qquad
116\rightarrow \texttt{source:t5c1n0},
$$

但这两个公开事实实际分别是 **116 的期初余额**和 **155 的期间费用**。正确对应是：

$$
134\rightarrow \texttt{source:t8c1n0},
\qquad
116\rightarrow \texttt{source:t4c1n0}.
$$

这不是引用格式略有差异，而是来源对象、期间角色和数值的直接冲突。报告没有替模型修复来源后重新赋予有效资格。

所以本轮应继续保持：

> **六个余额差算式执行，一条完整有效的余额差轨迹，零条被观察到的明细执行。**

另外，六个会话来自六个不同的最终模型。不能把它们混成某一个模型的六次采样，再写出“余额差类概率为 1”。对其中五个模型，这一次执行甚至没有提供一个完整有效的商状态样本。报告对计算结构和有效路线的分开记录是正确的。

P11 的 Final 只有 `"18"`，单位出现在 sibling message 中。按既有 Final-only 政策保留答案未定，而不是补成 PASS 或判成确定金融错误，也没有问题。**计算阶段允许从所选来源解释单位，与终局答案必须从实际 Final 提取数量，是两个不同的判定对象，不构成自相矛盾。**

这些失败属于 **Student 的实际行为结果**，不是本轮诊断程序必须“修好以后才算完成”的缺陷。

## 3. 参数、分母和旁路修订没有出现报告内的越界

公开工作量相互一致：

$$
7\times36=252,\qquad
7\times4793=33551,\qquad
7\times232603=1628221.
$$

七个打分进程加六个生成进程对应十三次加载；六个会话各两次响应、一次成功计算，对应十二次响应和六次工具执行。报告将这些量与训练量、新增数据量分别记录，没有混淆。

两处旁路名称更正也不构成本轮阻断项：更正的是旧面板的财务对象描述，报告明确披露了 `assess_with_side_labels.py`，没有声称未经 wrapper 原样执行，也没有将旁路名称更正用于修改本轮主测量或旧评分。**在当前报告证据范围内，可以接受这种披露完整、边界明确的旁路修订。**

## 4. 本轮真正留下的缺口

当前没有被验证的是下面这段联系：

$$
\boxed{
\text{有效行为类的训练质量移动}
\;\longrightarrow\;
\text{独立任务上的受益模型效用变化}
}
$$

不是前面的损失接线没有建立，也不是必须先让所有模型在原 L1 改走明细。

同时，**唯一 R 样本确实限制了方法层面的外推，但不抹去原固定支持干预的可解释性**。在固定 \(\kappa\) 的具体有限数据池上，P/Q 比较仍然是清楚的；没有被单独识别的是脱离这个具体文本、来源组织和任务实例的“抽象明细方法价值”。报告也没有越过这条边界。

因此，下一步不应再做一次“原 L1 是否切换路线”的诊断，也不应直接通过提高 R 权重、延长训练或修改 Harness 来追求正结果。应该把实验推进到**有多个有效样本的类质量方向干预，以及独立效用确认**。

# 二、建议的后续实验：多任务、双向类质量干预与独立效用确认

建议新建一个独立实验，研究问题明确为：

> **在固定任务边际、有效支持、类内物化核和训练协议下，对不同任务分别向两个方向移动有效行为类质量，哪些移动能够改善独立任务上的完整可验证轨迹效用？**

这里不预设 R 更好。**更偏向 D、保持原分布不动，以及所有候选都没有可确认收益，都允许成为结果。**

我建议使用下面这个规模：

| 对象            |                           建议规模 |
| ------------- | -----------------------------: |
| 新双支持任务        |                            3 个 |
| 复用的控制任务       |                            3 个 |
| 新教师采样         |            每个新任务 24 会话，共 72 会话 |
| 分布条件          |      共同基线 + 每个新任务两个移动方向，共 7 条件 |
| 配对训练种子        |                            3 个 |
| 新训练运行         |              \(7\times3=21\) 次 |
| 开发面板          |                           12 题 |
| 独立确认面板        |                           24 题 |
| 开发评测          |          \(21\times12=252\) 会话 |
| 确认评测          | 最多 \(2\times3\times24=144\) 会话 |
| Student 评测总上限 |                         396 会话 |

这些数目是**新方案的固定预算建议，不是已经获得的数据或已经启动的工作**。具体新任务和评测题的来源 ID，当前附件没有提供，需要在执行前用真实来源完成绑定，不能把本方案当成已经冻结的题表。

## 1. 固定新的研究总体，而不是悄悄延长旧实验

### 三个新双支持任务

优先选择三个不同来源、不同公司或报告中的真实任务，均具有两种充分关系：

$$
D_x:\ \text{期末量}-\text{期初量},
$$

$$
R_x:\ \text{期间各项真实增减的合计}.
$$

例如，同属净变动问题，但对应不同财务对象、不同表格组织和不同变动项目。**不是把原 L1 的数值换一遍，也不是从原 L1 改写几个句子。**

两个目标类必须按照现有完整行为商语义定义。不能只看最后的算式就把所有轨迹硬塞进 D/R：实际双路核验、实质修订或其他保留的行为差异，仍应按冻结规则分别处理。

### 三个控制任务

可以复用已接受的 G1、G2、F1，各三个有效包，共九包。父实验已经明确了这些包及其权重结构，不需要再次采样、重新判断资格或重做旧语义配对。

由此得到一个**新的六任务总体**：

$$
\mu(x)=\frac16.
$$

这不是原六任务实验的续跑。新基线与旧 P 使用的训练总体不同，因此不能把两者的得分差直接归因于“多样性更好”或“算法升级”。

## 2. 一次有界采样，建立每类多个真实有效样本

三个新任务各采集 24 个独立空历史会话，共 72 个。沿用原开放 Teacher 条件、T 指令、工具、反馈和停止政策。

**不提示使用 D 或 R，不提供候选公式，不隐藏端点，不在模型第一次选择 D 后要求它换一种方法。**

采样结束后再做离线有效性判定、完整行为归类和原样表示。每个目标商类至少需要四个独立生成、完整有效且在既有表示政策下可消费的会话。按预先固定的索引选择和分配规则：

$$
4\text{ 个有效包}
=
3\text{ 个训练包}
+
1\text{ 个同题未训练目标诊断包}.
$$

三个任务、每题两类，合计：

$$
3\times2\times3=18\text{ 个新训练包},
$$

$$
3\times2\times1=6\text{ 个同题诊断包}.
$$

加上九个旧控制包，得到 **27 个训练包**。

这里需要明确几个边界。

**第一，四个独立会话不是四个商类。** 同类样本可以表述不同，也可能出现重复文本；重复不能被包装成新增行为多样性。若诊断包与训练包文本重复，也不能称其为未见文本泛化证据。

**第二，其他有效类不变成失败。** 它们和未映射轨迹、失败、未定结果都完整保留。本实验仅在事先声明的两个目标类有限支持上构造训练分布，不把选入训练后的比例称为自然生成概率。

**第三，输入不足就停止，不补造。** 某个目标类不足四个合格包时，报告该固定采样条件下未建立所需输入，不换题、不追加轮次、不通过改写或复制来凑数。有效但超出表示条件的轨迹，也保留其有效性与表示限制，不通过截断伪装成原样可消费。

这一停止点属于**新实验输入是否成立**，不是要求旧诊断重新通过一个更高的 Gate。

## 3. 采用逐任务、双向干预，而不是同时提高全部 R 质量

新的共同基线 \(P_{\mathrm{new}}\) 在三个目标任务上均设为：

$$
P_{\mathrm{new}}(D_x\mid x)=\frac23,\qquad
P_{\mathrm{new}}(R_x\mid x)=\frac13.
$$

控制任务保持原选定单类支持。这里的基线质量是人为设定的实验参考，不是根据选出的三对三样本倒推自然频率。

设：

$$
\delta=\frac16.
$$

对每个新任务 \(x\)，建立两个条件：

$$
P_x^+(R_x\mid x)=\frac12,
\qquad
P_x^+(D_x\mid x)=\frac12,
$$

$$
P_x^-(R_x\mid x)=\frac16,
\qquad
P_x^-(D_x\mid x)=\frac56.
$$

**每个条件只修改这一个任务。其他五个任务完全不变。**

因此共有：

$$
P_{\mathrm{new}},
\quad P_{x_1}^+,P_{x_1}^-,
\quad P_{x_2}^+,P_{x_2}^-,
\quad P_{x_3}^+,P_{x_3}^-.
$$

这样设计有两个重要作用。

一是避免把“同时改变多个任务后的净效应”误解释成某个任务的边际价值。二是允许数据表明**向 D 移动更有利**，不把欠覆盖或更复杂当作 R 应当获得更高质量的理由。

每次只移动一个任务，所以全局转移质量仍为：

$$
\mu(x)\delta=\frac1{36}.
$$

不是通过同时改变三个任务，暗中把总干预幅度扩大三倍。

### 精确包权重

每个目标类内有三个训练包，固定：

$$
\kappa(\tau\mid x,z)=\frac13.
$$

受干预任务的每包全局质量如下：

| 条件                   |    每个 D 包 |    每个 R 包 |
| -------------------- | --------: | --------: |
| \(P_{\mathrm{new}}\) |  \(1/27\) |  \(1/54\) |
| \(P_x^+\)            |  \(1/36\) |  \(1/36\) |
| \(P_x^-\)            | \(5/108\) | \(1/108\) |

三个控制任务各有三个包，每包质量均为 \(1/18\)。每题总质量始终为 \(1/6\)。

仍使用原来的损失语义：

$$
\ell_\theta(\tau)
=
\frac{1}{L_\tau}
\sum_{u\in\tau}\mathrm{NLL}_{\theta,u},
$$

$$
\mathcal L_\pi(\theta)
=
\sum_\tau w_\pi(\tau)\ell_\theta(\tau).
$$

对同一参数，新的单任务接线关系为：

$$
\mathcal L_{P_x^\pm}(\theta)
-\mathcal L_{P_{\mathrm{new}}}(\theta)
=
\pm\frac1{36}
\left[
\overline\ell_\theta(R_x)
-\overline\ell_\theta(D_x)
\right].
$$

这可以作为针对新权重表的局部控制，不需要重跑旧 58 项或本轮 40 项控制。

## 4. 固定训练，不把协议修补混入分布干预

沿用既有基础检查点、LoRA 范围、优化器、每次十次完整遍历和最终检查点选择规则。三个种子仍可使用 11、29、47。

每个种子下的七个条件必须共享初始化、随机性配置、逐轮顺序、优化器初始状态和相同物理训练数据。**每次遍历全部 27 包，只改变损失系数，不通过不同重采样路径增加额外差异。**

新增材料的 Token 数目前未知，训练预算应在物化后按真实数组冻结：

$$
T_{\mathrm{target}}
=
10\sum_\tau L_\tau,
$$

$$
T_{\mathrm{sequence}}
=
10\sum_{\text{训练行 }r}\operatorname{len}(\text{input}_r).
$$

不能直接套用旧实验的 47,930 个监督 Token。

本实验不再增加 B0 校准。它要比较的是相同训练协议下不同 \(\pi\) 的差异，不是重新解释未训练模型的严格 JSON 适配问题。

Harness、解码器和评价政策也保持不变。来源绑定与 Final 交付错误继续作为模型结果测量，**不通过新增在线来源纠正、强制读证据或扩大单位别名，将这些失败先修掉再宣称分布干预有效**。

## 5. 主结果必须是独立效用，而不是路线偏好

建立两份分别冻结的评测面板：

| 面板     |   规模 | 用途               |
| ------ | ---: | ---------------- |
| 开发面板   | 12 题 | 测量有限方向效用，选择候选分布  |
| 独立确认面板 | 24 题 | 只确认已经选定的候选，不参与选择 |

训练、开发和确认之间应按公司／报告来源簇隔离，而不只检查页面是否重复。仍需披露预训练可见性未知、目的性选题等限制，不能称为天然无污染或总体随机样本。

每个面板划分三个等权组，开发每组四题，确认每组八题：

| 组别       | 研究作用                         | 防止的偏差           |
| -------- | ---------------------------- | --------------- |
| 双充分依据任务  | 完整公开材料下，D、R 或其他充分关系都可成立      | 不奖励“为了明细而明细”    |
| 明细整合相关任务 | 真实问题要求特定变动构成，或原材料本来不提供充分端点关系 | 不靠事后删去端点制造 Q 优势 |
| 其他财务任务   | 比例、指标定义、跨期汇总等回归检查            | 不只测被增加质量的方法对应任务 |

第二组的依据必须来自**真实任务和完整来源的实际要求**，不能仅因研究者想看到 R，就在问题中增加“请使用明细”，或删除原本存在的充分信息。允许模型采用任何其他可验证关系。

主要效用定义为：

$$
\widehat J_\nu(\theta)
=
\sum_{g=1}^{3}
\frac13
\cdot
\frac1{n_g}
\sum_{i\in g}
\mathbf 1
\{
\text{完整可验证轨迹 PASS}
\}.
$$

这是**确认完整有效轨迹的产率**。答案 PASS／FAIL／UNDETERMINED、来源绑定、实际执行和 Final 交付分别报告。未定不会从分母删除，也不被解释成确定金融错误。

路线选择只是机制观察。即使模型一直使用 D，只要在固定目标上产生真实效用改善，仍然是有价值的结果；反过来，多执行 R 但完整轨迹效用下降，不构成正收益。

语义评审应尽量隐藏条件名称、种子、NLL 和模型身份，混排会话后按统一政策判断。**变体身份盲化不能被称作独立金融专家认证**，但比知晓哪条是“希望改善的 Q”再评分更合适。

## 6. 用开发集测方向，用独立确认集判断是否真的有收益

设：

$$
\theta_{a,s}
=
\operatorname{Train}
(\theta_0,\pi_a,\kappa,\text{固定预算},s).
$$

对每个任务，可以计算一个有限方向效用量：

$$
\widehat G_x^{(\delta)}
=
\frac1{3}
\sum_s
\frac{
\widehat J_{\nu_{\mathrm{dev}}}(\theta_{x^+,s})
-
\widehat J_{\nu_{\mathrm{dev}}}(\theta_{x^-,s})
}{
2\delta
}.
$$

这个量比原 \(C_{\mathrm{fit}}\) 更接近下一步需要回答的问题：**改变该任务的类质量，受益模型的任务效用如何响应？**

但是必须称它为**有限步长方向效用估计**，不能直接命名为已经验证的理论 Contribution。有限 \(\delta\)、有限训练过程、greedy 指标和三个种子，都不自动提供一阶极限或稳定总体效应。

而且，不能只看 \(\widehat G_x^{(\delta)}\) 的正负来选更新。两个方向可能都比基线差，只是其中一个“差得少一些”。

因此候选选择应直接比较：

$$
\overline\Delta_a^{\mathrm{dev}}
=
\frac13\sum_s
\left[
\widehat J_{\nu_{\mathrm{dev}}}(\theta_{a,s})
-
\widehat J_{\nu_{\mathrm{dev}}}(\theta_{P_{\mathrm{new}},s})
\right].
$$

预先固定规则：

> 在六个移动候选中选择开发集平均完整轨迹收益最高者；只有其收益严格为正才移动，否则保持 \(P_{\mathrm{new}}\)。同分优先基线，其余按预先固定的候选顺序处理，不用 NLL 或答案率临时破同分。

选择结果和对应模型身份封存后，才对独立确认面板执行：

$$
P_{\mathrm{new}}
\quad\text{对比}\quad
\pi_{\mathrm{selected}}.
$$

三个种子最多六个模型、每模型二十四题，共 144 个确认会话。**不得看到确认结果后换成开发集第二名，也不得重新调整面板。**

若开发阶段选择“不移动”，就没有一个已选定的新分布需要确认；可以报告基线的独立表现，但不能把两个相同分布的重复运行包装成一次有效更新验证。

这使实验从“人为指定一个 Q，观察它有没有变化”，前进到：

> **比较有限方向 → 根据开发效用选择或拒绝移动 → 在未参与选择的任务上确认。**

它仍然不是完整的锚定能量 VTDO 算法验证；但它开始建立**类质量方向、受益模型效用与独立确认之间的实证联系**。

## 7. 保留机制诊断，但不让它重新成为主线

前述六个同题未训练目标包，可以用于辅助比较不同条件的文本拟合响应，不再新增原 L1 greedy 重复。

其解释仍要克制：这是同一训练任务、不同生成会话的目标文本诊断，不是新任务泛化；有重复文本时如实标明。NLL 仍然不能转换成类概率。

自主行为机制则主要从开发和确认会话中提取，继续分别记录实际算式、模型声明来源、完整有效路线和 Final 交付。不要另起一轮专门要求模型证明它“会走 R”的实验。

# 三、执行顺序、停止条件与结果解释

## 1. 执行顺序

建议将后续组织成一次连续、有界的新实验：

**来源与规则登记 → 固定量教师采样 → 离线资格与商类判断 → 冻结支持、\(\kappa\)、权重和实际预算 → 七条件三种子训练及开发评测 → 封存候选选择 → 独立确认 → 一次收口审计。**

各处只检查进入下一环节所需的实际输入，不拆成不断重复的“预检—同内容独立审计—再次预检”。

本轮已经关闭的旧训练、旧 84 会话、原 L1 六会话及全部历史评分都保持不变。

## 2. 必须预先固定的停止边界

| 情形                    | 处理                            |
| --------------------- | ----------------------------- |
| 新任务的两条充分关系不能由真实来源成立   | 不启动该方案的采样，不用合成数值或错误解释补足       |
| 固定采样结束后，指定类的有效可消费样本不足 | 保留结果，后续训练不启动；不补采、不换题          |
| 新训练对照发生实现故障           | 保留失败和已启动记录，不暗中重试或替换模型         |
| 开发候选没有优于基线            | 允许保持原分布，不能加大步长寻找正结果           |
| 确认集没有收益               | 按原方案收口，不改评价政策、不换候选            |
| 出现来源、接口或 Final 缺口     | 按冻结政策计入结果，不自动扩展为 Harness 修补阶段 |

这里的停止不是把负结果称为整个理论失败，而是保证每次实验最终回答其已登记的问题。

## 3. 结果应如何解释

| 新实验观察                  | 可以支持的结论               | 不能支持的结论                |
| ---------------------- | --------------------- | ---------------------- |
| 同题诊断拟合改善，但独立完整轨迹效用没有改善 | 固定材料响应未转成当前确认面板收益     | 权重完全无效、Contribution 为零 |
| 某个方向在独立确认中三个配对均改善      | 该有限支持、协议和面板上的方向一致局部收益 | 普遍最优分布、总体统计显著性         |
| 平均改善，但种子或任务组有退化        | 有限净收益与明确异质性、取舍        | 稳定无损提升                 |
| 更偏 D 的方向被选中并获确认        | 当前参考分布下，更偏 D 的移动更有利   | D 永久优于 R、复杂轨迹无价值       |
| R 执行增加，但完整轨迹效用下降       | 行为变化与效用变化脱钩           | 更多明细执行就是训练收益           |
| 开发阶段保持基线               | 当前候选族没有触发有据可依的移动      | 所有可能分布都无法改善            |

三个种子重复的是同一批任务，不能把 396 个会话当成 396 个独立任务。这个预算也不是已经完成的统计功效论证；小效果仍可能无法被可靠分辨。

# 四、最终建议

**本轮不修补、不追加、不重新审计同一对象，按当前证据边界收口。**

下一轮最值得推进的不是“再让 Q 更偏明细一点”，而是：

> **在每类多个真实有效样本、多个任务和固定类内核上，分别检验两个类质量移动方向；根据开发效用决定是否移动，再用独立任务确认。**

这样既不否认本轮已经测到的拟合响应，也不把来源绑定失败变成无止境的工程修复入口；更重要的是，它把实验从**“质量改变是否影响模型”**，推进到 VTDO 真正需要回答的 **“什么质量改变对受益模型有用，以及这个判断能否在独立任务上成立”**。
