新执行环境显式设置 `CUBLAS_WORKSPACE_CONFIG=:4096:8`，并在 CUDA 初始化前校验，保留原确定性算法设置。新的 provider 会保存底层异常类型、文本和 traceback；没有 cause 时不伪造诊断，UNKNOWN 和实际调用计数保持原语义。旧最小 CUDA 矩阵诊断已证实缺少配置可触发错误、设置后通过，本次不重复该诊断；它不能补造旧科学调用已经丢失的错误原文。

温度前向和反向仍使用 `log_softmax(logits/T)`，T0.5 同时包含归一化及 1/T 导数。分母 700 含零奖励，完整轨迹含真实 EOS，不用 SFT mask、不作长度归一化、不缩放旧 gJ。C 指数 0.8、N 指数 0、原 RMS、锚点和更新数学不变。真实训练仍从 `step0596_step` 起，固定 q 执行 597 至 894，保存 745/894，不做 894 outer。

## 必要核验与评分顺序

本次只执行恢复绑定、原子 claim/返回记录、确定性环境与中断等待计时的定点 CPU 核验，以及正式冻结包实际入口依赖检查；不重跑已通过的温度数学、完整父点、旧诊断或历史全量测试。实际启动后检查最早模型返回的 condition/request/receipt 和资源观测，不能仅凭进程存在或失败 episode 文件判断采样成功。
