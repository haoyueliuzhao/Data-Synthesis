# 跨市场PDF运行时与评价隔离实现

本说明记录2026-09-26新增的独立实现，不改变旧SEC评价、原B结论或九个已训练保存点。目前这些代码仅经过合成CPU控制，**尚未启动真实模型生成、私有评分或新增训练**。能否执行4,860会话仍取决于发行人／财务／180题面板准入以及单独冻结的执行协议。

## 公开运行时

`fixed_kernel_cross_market_runtime_20260926.py`保留原英文SYSTEM、每次一对象、首个Final即停止、32次响应／工具上限以及原五种动作：`read_source`、`calculate`、`select_max`、`compare`、`lookup_selected`。模型上下文仍是有限的given-sources环境，不新增任意PDF读取工具，也不声称模型可在线浏览完整原PDF。完整PDF与逐页文本作为不可变审计引用保留。

输入使用多个真实PDF的原文证据和财务记录，逐记录绑定原PDF hash、URL及`pdf://<sha>#page=...`定位。不构造SEC companyfacts，不写`us-gaap:`伪概念，也不把证券代码作为CIK。公开来源须由面板编译器按固定窗口／预登记指标产生全部合格记录，不能只公开私有解法需要的叶子事实。运行时不负责选择题目或判定财务准入。

新单位合同支持CNY、HKD、USD及各自的千／百万缩放，比例和百分比仍为无量纲单位。不提供汇率，不允许跨币种转换、加减或相除。源金额保存为原币基本单位，原始列示的正负号和原始单位证据仍在记录中；不对成本机械取绝对值。默认选择比较单位跟随首个实际输入，不默认为USD。

## 离线财务证明

保留原自由符号证明原则：首个Final正确，而且执行过充分的来源、单位、实际期间及算术／完整峰值选择依赖。仅命中答案常数不通过。均值需三期、峰值查找需完整比较及选中实际期间；双路径任务支持已独立准入的端点和分量关系，负数成本按已证实的加法系数处理。

原评分器存在USD／US-GAAP源身份假设，因此新增PDF原生绑定和币种算术适配，不能标记`financial_rule_unchanged=True`。新报告分别记录`source_currency_adapter_changed=True`与`financial_support_principle_unchanged=True`。既有证书及见证DAG结构本身不依赖SEC，可用于真实PDF财务关系；其来源、期间、口径和完全性必须由面板准入证实，不能靠记录类型名取得信用。

私有证书结构损坏、私有绑定缺失等准备错误在进入模型响应评分前抛出异常，不记作Q=0。模型自己选择了不充分工具、错误期间、错误币种或错误Final，才属于可观察的模型失败。所有保存的会话用同一PDF运行时完整重放。

## 执行桥与保存

`fixed_kernel_cross_market_evaluation_20260926.py`复用原decoder、采样、token回执、逐会话保存和已提交会话盘点，但通过隔离的函数命名空间接入新运行时；不修改旧模块全局变量。随机及greedy共享各模型参数点身份，账本键包含`point_id + mode + index`，不会把相同序号的不同模式会话合并。种子配对应按训练seed／task／repeat生成，不含arm。

每个真实`generate`调用或评分案例在执行前登记并消耗额度；中断记录不退款，重复物理尝试也不能绕过预算。失败、OOM或资源等待向控制器传播，不填Q=0。评分使用最多12个spawn CPU worker，每个已评分案例独立原子提交，恢复仅补缺失项。

评分入口先验证18个完整cohort、9个真实模型点、恰好4,860条已保存轨迹、相同训练seed下跨arm配对采样种子，以及所有生成worker已经退出的全局seal。**通过此屏障之前，执行桥不会打开或hash私有索引／原生绑定／答案bundle。** 准备阶段构建和审查金标准与执行阶段隔离属于不同边界，不能把金标准准备冒充模型评价。

## 必要核验

当前16项合成运行时控制覆盖三币种均值、完整峰值查找、错误期间、双路径毛利差值／增长率、成本负号、答案常数不充分、首Final停止、PDF定位／原文hash变更拒绝、币种冲突及私有证书损坏。另7项执行桥测试覆盖冻结模块不变、模式安全账本、幂等提交／冲突、尝试不退款、未预留调用拒绝、路径约束和全局seal之前不读私有资产。所有测试均不加载Student、不读取新真实财务答案、不使用GPU或网络。

这些测试不证明真实面板已准入，也不报告任何训练价值；实际运行结果和耗费应由最终登记／完成记录另行发布。
