# FinQA 五臂训练与机制实验完整报告

报告日期：2026 年 10 月 5 日。本文时间均为北京时间。

本报告汇总 V18 固定共同材料上的五臂训练、十五个最终模型的 dev883 评价，以及 C 方向与 N 同点机制实验。训练数值实现沿用已冻结的 V18 版本，后半程由 V22 八卡评测控制器接续。整轮于 **10 月 5 日 04:56:34 完成**，并非仍在等待评价。本文不把先前材料修订的通过率、普通训练收益或完成率当作 VTDO 增益。

## 主要结论

1. **普通训练相对未训练 Base 有较大数值提升。** Static 的三 seed 平均执行准确率为 41.68%，原始 Base 为 3.74%，相差 37.94 个百分点。这包含对本轮输出和提交协议的适应，不能全部解释为金融推理能力提升，更不能记为分布优化的增量。
2. **预登记主效应 Full−Static 的均值为正，但 seed 间不稳定。** 执行准确率差为 +2.53 个百分点；三个 seed 分别为 +6.68、−6.46、+7.36 个百分点。正式统计没有置信区间或 p 值，不能据此宣称显著或稳定收益。
3. **C-only 的跨 seed 平均最高，Full 未超过 C-only。** C-only 为 48.51%，Full 为 44.21%；Full−C-only 三个 seed 均为负，平均 −4.30 个百分点。这是本轮数据不支持完整方法优于其 C-only 消融版本的直接证据，但不等于单独证明 N 在所有场景都有害。
4. **C 方向诊断只给出有限、依赖解码方式的支持。** 正方向相对 Static 的正式混合准确率平均 +0.74 个百分点，三个 seed 有一个为负；正方向都高于反方向，但有一个 seed 只是“比反方向少受损”。按既有评分作事后分解，greedy 的正方向−Static 在三个 seed 全部为负，平均 −4.17 个百分点。
5. **N 在三个 seed 均实际改变了分布，但未得到一致的局部收益。** 同起点 N 控制的 Full−C-only 为 −5.83、+1.67、+1.39 个百分点，平均 −0.93 个百分点。不能写成“N 没有激活”，也不能写成“N 的有效性已验证”。

总的判断是：本轮完成了可复核的训练、配对评价和机制对照，观察到普通学习收益与部分分布干预的数值收益；**尚未建立完整 VTDO 相对消融版本的稳定优势，亦未建立过程可靠性、独立测试集泛化或动态收敛的证据。** C-only 的描述性排序不改变预登记的 Full 主候选和 Full−Static 主比较。

## 评价与统计口径

### 主 dev

每个最终模型评价同一完整 dev883 名册。固定公开工具协议为 `finqa-public-reasoning-v2`，工具序列化为 `qwen2.5-native-tool-call-v1`，harness 为 `bigfinance-derived-vtdo-v7`。使用 greedy，temperature0、top_p1、top_k0，seed 字段为 20260928；单次输出上限 2,048 token，完整上下文上限 24,576 token，最多 32 轮响应。

公开输入不含作者答案或参考程序。每模型完整生成封存后再按原规则读取评分参考。缺失／非法提交及不可执行程序是已知错误，按 0 计入原 883 分母；真正评分未知不允许改记 0。本轮十五份评分中两个指标均为 `scored=883, unknown=0`。

- 执行准确率：提交程序经原生 FinQA 执行器执行，结果是否与参考结果相符。
- 程序准确率：原生程序等价判定，不是简单字符串相等，也不等于完整推理过程正确。

因此本轮数值不能直接与不同工具、提示词、提交语言或无工具 FinQA 设置混用。

### 配对统计

主效应是 **Full−Static 的执行准确率**。登记的关键次比较为 Full−C-only、Manual+−Static、Manual−−Static。先在同 seed 的同 883 题上求逐题 0/1 差，再对三个 seed 的平均差等权平均。Static−Base 单列为普通学习效应。

正式汇总没有 bootstrap、t 检验、置信区间或 p 值，相关字段为 null；也未声称统计功效充分。本文的 seed 样本标准差以 `n−1=2` 为分母，只表示三个已运行 seed 的波动，不是标准误或置信区间。一个 arm 的 2,649 次回答仍是同 883 题的重复，不是 2,649 道独立问题。来源簇内均值也只是描述性统计。

## C 方向机制结果

在同一真实 step298 起点，比较先验分布 Static、第一次 C-only 正方向分布，以及围绕同一先验构造的反方向分布。三个条件均比较 149 步训练后 step447 的模型。Static 与 positive 复用预定主线保存点，reverse 实际新增短训练；reverse 不是主线 Manual−。

每条件评价同一 120 道校准题，两次 temperature1 随机生成加一次 greedy，共 360 条。正式混合均值不挑选每题多次生成中的最好答案。

十五份 C／N 机制评分均为 `unknown=0`，合计5,400条完整保留；正式机制汇总不声称统计显著，没有新增置信区间或 p 值计算。

| 11 | 171／360，47.50% | 180／360，50.00% | 163／360，45.28% | +2.50 pp | +4.72 pp |

## N 同点机制结果

N 是相对固定先验的欠覆盖量，形式为 `max(0, log(r) − log(π))`，不是正确性置信度或“可信分数”。Full 的 N 指数为 0.2，C-only 为 0。

局部对照固定在原 C-only 的 step596 起点，复用相同已有反馈和贡献证据，分别使用关闭 N 与开启 N 的更新分布，再比较相同 149 步后的 step745 模型。这里的条件名 Full **不是主线 step1490 Full 最终模型**。

### 实际同点构建

三个 seed 的既有主线 C-only 与 Full 都没有满足严格同点复用条件。正式检查中，G、gJ、虚拟参数、pullback、任务权重 μ 和奖励向量相同；C、反馈封存对象，以及联合 θ／Adam／RNG／π／prior／日程摘要不同。因此不能仅凭奖励相同或部分梯度摘要相同复用主线 Full。

实际三者均执行事前登记的固定 C-only 锚点 fallback，各新增 149 步 N 短训练。它恢复原锚点，而非接在 C reverse 模型后继续训练。连同各自 C reverse149 步，每个 seed 新增 298 步，三个 seed 共 894 步；没有新增反馈或 API 请求。

## 结论限制与后续研究建议

首先，三个训练 seed 的差异较大，且没有预登记的显著性检验。本轮只能报告描述性效应、方向一致性和不一致性，不能给出未计算的置信区间、显著性或“确定提升”判断。

其次，主线 Full−C-only 是完整训练路径的总差；局部 N 实验才固定了起点和已有反馈。两类差值不能混称为同一个 N 因果效应。C 方向实验只覆盖预定的早期447点，N 控制只覆盖745点，不能代表所有 outer 或终点附近行为。

再次，机制使用已曝光 calibration120，回答重复不增加独立题目数；dev 也不能替代尚未打开的 public test。数据经过候选正确性和过程资格筛选，语义标注包含 AI 裁定，来源存在官方 split 重叠，均限制外推范围。

最后，程序执行正确和程序等价都不是公开推理过程可靠、金融论证充分或轨迹 CompletePass。错误模式的结构统计也不是逐条推理审计。

以下仅为**未来研究建议，尚未实施，不改变本轮结论或保存点**：

- 继续把 Full−Static 作为本轮既定主效应，并单列 Full−C-only 的全 seed 负向结果，避免用最佳消融版本替换主候选后宣称整套方法成功。
- 针对 C 的随机／greedy 差异，在独立登记的新轮次明确解码口径和配对设计后验证；不要据本轮 dev 回写提示词、解码参数或数据资格规则。
- 对 N 的效应先区分非零分布移动、不同起点的反馈依赖、提交有效性和最终准确率。当前“小幅回归先验削弱有用重分配”等解释仍是假设，需独立对照而非从相关性断言。
- 若扩展 seed 或测试范围，先明确来源簇相关性、推断目标、主次指标和统计方法；public test 及 Experiment 5 仍须依原授权与登记条件另行推进，本报告不自行启动。
