## Statistical Boundary

The formal report authorizes only:

```text
bounded-policy finite-sample empirical q and success-conditional pi
```

It does not authorize:

- pooling Unconditional and conditioned Cells;
- pooling conditioned Paths;
- conditioning on empirical Route Signature;
- cross-task State probability;
- Path causal effects;
- simultaneous multinomial coverage;
- unrestricted natural-agent frequency;
- current-denominator repair or deletion;
- VTDO, training, release, or production claims.

Rollouts are secondary repeated measures and tasks remain the primary statistical units. The
Wilson intervals quantify finite-sample uncertainty only within each exact Cell.
