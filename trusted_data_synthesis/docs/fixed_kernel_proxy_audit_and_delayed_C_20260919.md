## A. 真实向量数值影响

输入固定为原十二轮的真实theta/m/v/step、G/gJ/a、当前pi、C、pi_next和反馈登记。
原a作为实际CUDA结果；CPU原算式重建、高精度相减式及稳定参考分别标注，不把
CPU结果冒充CUDA复跑。原算式不直接修改，旧结果继续保留。

记h为clip后的（含maximize符号）梯度，a1=1-beta1、a2=1-beta2、
s=sqrt(beta2*v+a2*h²)、c2=sqrt(1-beta2^(t+1))、d=s/c2+eps。
固定实际历史矩时，稳定导数为：

```
dU/dh = lr/(1-beta1^(t+1))
       * ((a1*beta2*v - beta1*a2*m*h)/(c2*s) + a1*eps) / d²
```

s=0且h=m=0取正确极限。非空矩允许负导数，绝不裁零。完整全局L2 clip的径向
导数仍纳入。参考用FP64；冷启动同一可表示输入、零坐标、非空负导数与激活clip
仅做必要小型CPU控制。[AdamW算法来源](https://docs.pytorch.org/docs/2.7/generated/torch.optim.AdamW.html)。

以下工程门限在读取实际向量比较结果前固定，不解释为统计显著性阈值：

- 用非控制任务的mu*pi加权RMS比较C/mu，参考与原保存C的相对RMS误差须≤1e-3。
- 加权TV(pi_reference, pi_saved_next)须≤1e-5。
- a的误差、cosine、C符号翻转及幅度分层同时报告；不单凭微小坐标变号改判旧结果。
- 任一实际点超门限或参考无法定义，禁止自动启动Delayed-C，先单列数值问题；
  不把稳定公式和时机修改混成一个单因素结论。

类梯度矩阵未在旧轮持久化。必要重算明确登记为最多十二次全类遍历：42,564包、
215,307,588序列token，不能说是纯读旧C。只有真实参数、材料、当前pi、优化器、
虚拟点及反馈内容等相应绑定一致，才共用计算；实际唯一遍历数另报。

## B. 分repeat方向与影响

两个repeat各保持180分母及全部零项，计算C1/C2和各自建议delta_pi；报告
S12=sum(C2*delta_pi1)、S21=sum(C1*delta_pi2)、加权cosine、正项任务/CIK集中度、
逐正项删除对C和pi的敏感性。删除项替换成零，不重新归一化固定分母；半边全零
标记无信息并保持pi，不重新分组或补采样。自评分S11/S22只作描述，不充当预测验证。

最多对已有652条正奖励轨迹同点、同Token各回放一次；最多166,346个原采样输出
token，完整前缀与重算工作另记。零项仍占原分母，不再GPU回放。额外generate=0，
财务评分=0。逐轨迹向量存CPU后，所有分半、删除与投影复用，不为统计变体再跑GPU。
只读取正项需要的保存会话，非正项使用已封存登记/评分，不重扫全部4,320条会话。

矩阵及逐轨迹向量使用/data1项目下本次独立缓存目录，不占仅余约49GiB的/tmp卷，
不提交模型、原始会话、矩阵或向量。最多两个独立审计worker，按已测单进程峰值
保守预留，GPU剩余≥60GiB、主存可用≥512GiB才放行；不干预其他用户作业。

审计以完成十二个登记点（允许有绑定证据的复用）的数值影响、冷/热启动方向
可靠性及集中度比较结束。不要求得到理想结论，不扩为无止境的验证。
