# FinQA V24：训练、反馈、评价与实际干预分布的只读审计

日期：2026 年 10 月 5 日；本文时间均为北京时间。审计对象为已完成的 V18 五臂实验。本次按用户提供的审计文本，在真实完整数据上补齐统计；用户文本链接中的 Markdown/ZIP 未在本地取得，本文不声称运行了该 ZIP 中的原程序。

## 1. 结论先行

本次确认了三种具体限制：**校准集的公司/报告来源高度集中、反馈的正奖励机会不均、真正可被 π 调整的支持只有训练核的一部分**。但是，不能把这些事实合并成“测试集太窄导致 Full 退化”。

1. 实际训练744题来自 **80家公司、130个公司年度报告**，不是原始 train 的741份报告。反馈350题来自33家公司、39份报告；校准120题仅来自9家公司、11份报告，其中 GS 与 JPM 合计84题，占70%。
2. 从候选1000题到训练744题，公开词面“差值/变化”类保留率为63.33%，“总和/总量”为68.42%，“比例/百分比”为80.68%。筛选改变了构成，但输入长度证据不支持“最终核明显更短”；本审计未使用金标准程序，不能将词面类别或长度称为真实难度。
3. 229道多状态题占训练任务质量30.78%，Manual 可调的87题占11.69%。24次自动更新每次都实际改变全部229题；C-only/Full累计更新剂量中，前10题仅占7.69%/7.52%。因此是**干预覆盖有限**，而非“有干预的部分又几乎都落在极少数题上”。
4. 16,800次反馈中正奖励6,490次，285/350题至少成功一次，65题从未成功。比例/百分比类占反馈题数36.29%，占正奖励45.02%；这是非零反馈机会的偏移，不等于梯度贡献占比。
5. 训练744与dev883的公开意图代理 TV 为0.0630，输入规模 TV 为0.0112；并未观察到这些粗粒度代理上的巨大错配。来源重合与来源构成差异仍存在，不能由粗代理相似推断语义分布或推理难度相同。
6. dev执行准确率的三seed均值差仍为 Full−Static **+2.529pp**、Full−C-only **−4.304pp**。逐一删除报告/公司，以及固定粗分组上的八种描述性标准化，都没有逆转这两个总体方向。Full−Static 原来各seed为正、负、正，这种seed间不稳定性也没有消失。

总体判断：本审计把“数据有风险”落实为可量化的限制，但**没有找到足以把 Full 相对 C-only 的负差归因于粗题型比例、某一个来源或少数干预题的证据**。这不证明数据完全无关，也不证明算法实现或设计必然正确。未测量的精细行为差异、梯度交互及已有的随机反馈/greedy评价目标差异仍是独立待检验问题。

## 3. 定义：本次实际测量了什么

### 3.1 公开属性

公司采用原始来源代码，不做行业分类或跨代码法律实体合并。报告组使用原始 `finqa:report:<company>/<year>`，同公司同年度不同页归为一组；公司跨年度仍可能重合。任务键统一为 `finqa/<task_id>`。

题面意图代理是对公开问题做固定regex匹配，主类别互斥，优先级为：`percent_change → difference_change → ratio_percentage → sum_total → average → minmax → count → other`。同时保留全部命中标记，但正文使用唯一主类别。“total percentage”等多命中题只按固定优先级归类。这不是作者运算标注、金融指标分类、过程需求或难度真值。

输入规模为问题字符数加所有公开source内容的紧凑JSON序列化字符数；使用Unicode字符，不是token数或训练序列长度。分箱固定为 ≤2000、2001–5000、5001–10000、>10000；问题单独分箱为 ≤79、80–119、120–199、≥200字符。表格行列、年份、问题长度等完整分布也保留在附件，不据结果再调整阈值。

### 3.2 权重、集中度与差异

普通人口统计对每道题等权。来源集中度为 `HHI = Σ p_g²`，`1/HHI` 仅称“等效来源多样性”，**不是统计有效样本量**。同时给出Top-1/5/10份额与组大小分位数。

离散分布差异使用 `TV(p,q)=0.5 Σ|p−q|`，范围0–1；附件另存以2为底的Jensen–Shannon差异。不设任意“严重错配”阈值。同一分组维度上的TV可以比较；公司/报告ID的差异不能直接当成语义难度差异。

训练名义质量与更新剂量分开：

\[
\mu(x)=1/744,\qquad w_P=\mu(x)\pi(z\mid x)/n_{xz},\qquad
d_{x,t}=\mu(x)\operatorname{TV}(\pi_{t+1}(\cdot\mid x),\pi_t(\cdot\mid x)).
\]

三seed统计先在各seed内保持配对，再等权平均。本文准确率差的 `pp` 表示百分点，不是相对百分比。相同问题在三个seed的重复评价不计成三道独立问题。

## 6. 名义监督质量与真正的干预剂量

### 6.1 π不会改变任务级公司/题型总质量

对同一任务的所有状态与包求和有：

\[
\sum_z\sum_{P\in(x,z)}\mu_x\pi(z\mid x)/n_{xz}=\mu_x.
\]

因此，按任务定义的任何公司、报告、意图、输入规模分组，其正式包权重总质量始终等于该组的任务μ之和；C、N与Manual改变的是同题内部状态/行为分配，而不是题目边际。按实际记录复算的最大任务质量误差为 `4.337e-19`。这验证的是名义loss质量守恒，不是实际梯度范数、优化器步长或行为影响相同。

包内使用目标token均值，包多或序列长不能直接当作额外任务权重。Static的χ=0、χ=1、已登记null singleton质量分别为74.81%、11.88%、13.31%；Manual+将χ=1质量改为13.56%，Manual−为10.28%。χ来自既有过程映射，不是独立语义真值认证；null只对应99个已登记单包singleton，不能和515个单状态任务混称。

### 6.2 支持覆盖与局部剂量

| 项目 | 实际覆盖或TV | 正确含义 |
| --- | --- | --- |
| 单状态 | 515/744＝69.22% | 题内π没有可调整自由度 |
| 多状态 | 229/744＝30.78% | 自动更新可直接调整的任务支持 |
| χ灵活 | 87/744＝11.69% | Manual归一化后可实际改变的支持 |
| Manual+ / Manual− 全体加权TV | 0.016735665 / 0.016020423 | 在87题内部平均条件TV约14.31% / 13.70% |
| 24次自动更新的单次全体加权TV | 0.006129–0.008703 | 在229题内部平均条件TV约1.99%–2.83% |

以每题条件TV大于 `1e-12` 为实际移动阈值，24次C-only/Full更新每次都移动229题，非零C也覆盖这229题。该阈值用于排除数值零，不用于定义“足够强的干预”。

支持子群并非全部来自一种题型：多状态229题中，比例76、差值42、百分比变化35、其他38、总和18、均值14、数量3、极值3；χ灵活87题中相应为27、14、8、21、10、6、0、1。两子群分别来自67/41家公司、97/54个报告组；覆盖缩小，不等于全部集中到同一来源。

## 7. 反馈正奖励与干预/评价的对应

### 7.1 正奖励机会有偏移，但不是只由少数题反复贡献

24次反馈各350题×2次生成，固定分母共16,800；6,490次正奖励，C-only为3294/8400，Full为3196/8400。每道题在全部反馈中出现48次，285题至少一次正奖励、65题一次也没有；最高40/48次，没有题48次全正。

65题占18.57%，在该有限采样中未提供 `Q>0` 的score-function项，不能据此断言它们本质不可解，也不能自动把它们定义为金标准“难题”。正奖励按题归一化后的前10题份额为5.855%，任务1/HHI为239.44；两者不是独立样本量或梯度权重。

按每次outer的两个repeat成功题集合计算，交集43–119题、并集158–220题，Jaccard为0.2443–0.5409；不是两个repeat总在同一批题成功。24个cohort seal各异，但只有21个point ID，且重复任务/模型轨迹存在依赖，不可把24次反馈当作24个独立实验。

正奖励的公司Top-1/5/10为15.285%/45.994%/64.422%，HHI为0.064996；报告Top-5为34.931%，HHI为0.043487。相对反馈原人口的公司Top-5 44%、报告Top-5 33.429%，来源集中度有所上升，但没有从原分布突然坍缩到单一公司。UNP/IP正奖励为992/872次，其原始题数50/44也较大；不得只看正奖励总数、不看暴露分母。

### 8.3 描述性标准化：换粗类别权重能否改方向

对意图与输入规模分别计算，**不构造多维交叉小格**。令稳定共同支持 `H={h:目标题数>0 且 dev题数≥20}`，计算 `Σ[h∈H] 目标归一化份额(h) × dev组内配对差(h)`。同时报告正质量共同支持与稳定H覆盖率，不为缺失格填值。
