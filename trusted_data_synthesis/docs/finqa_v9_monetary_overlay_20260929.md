# V9 同钱包前瞻费用额度追加：800 → 1200 元

## 授权与范围

用户明确回复：**“批准1200元总上限及上述风险”**。本次是原钱包总额度增加
400 元，不是新建另一个 1200 元钱包。授权绑定已经完成的 V9 全矩阵费用前检
`ceeb89519387dfd98e47015128137b9fe901689644c9b4f42391782f399ce4bc`，接受
13,022 次固定生产处理仍可能无法全部完成的风险；不完整时不能用成功前缀开训。
此授权不新增 Probe 生成、技术审阅批、重试或其他模型。

实现位置为 `finance_research/probe_budget.py` 的
`apply_v9_monetary_amendment(...)`。本文件描述实现及临时数据库验证，**不单独证明
真实钱包已经追加额度或生产请求已经开始**；实际应用由独立冻结登记和账本追加事件证明。

## 不重写历史

原始 `metadata.config` 字节及其哈希保持不变，仍记载原 800 元硬上限、700 元告警和
258,000 次请求上限。原请求、计费、计数器、在途/UNKNOWN 预留、旧 UNKNOWN 确认记录、
V8 请求分区及其 config 绑定均不改写。生产请求子额仍为 18,000，缓冲区仍不可支用。

唯一写入是追加一条 `v9_prospective_monetary_amendment` 元数据及完全匹配的审计事件。
其中绑定用户费用决定的完整不可变记录、原 config 哈希、分区、当时计数器、历史请求摘要、
旧 UNKNOWN 确认摘要和追加时间。不释放历史 2.228224 元 UNKNOWN 保守预留；不声称取回了
缺失 usage，也不把预留当成供应商已收费。

只允许在原 35,336 次请求已收口、pending=0、未处置 UNKNOWN=0、无 halt、生产子额消耗=0
的启动前状态登记；generation=16,286、technical_review=108 也须匹配。费用与请求行必须
守恒，原有支出加持有额度不能已超原 800 元。严格拒绝缺少/更换用户授权、改前检、改额度、
改钱包身份或重复不同追加决定。完全相同的决定只做幂等读取，不再次追加事件或清除后续 halt。

## 运行时字段与停发

追加后快照同时给出：

| 字段 | 含义 |
|---|---|
| `hard_cap_microcny=800000000` | 不改写的原始登记上限 |
| `effective_hard_cap_microcny=1200000000` | 本次明确授权后用于新预留的总上限 |
| `remaining_exposure_microcny` | 有效 1200 元减已结算费用、全部在途及 UNKNOWN 预留 |
| `original_remaining_exposure_microcny` | 仅供历史比较的原 800 元余额，后来可为负 |
| `monetary_amendment` | 完整追加授权记录 |

没有这项明确追加记录的旧钱包仍按原字段和原上限运行。每次新请求在 SQLite
`BEGIN IMMEDIATE` 事务内重新读取有效额度；即便 `ProbeBudget` 实例在追加前已经创建，
也不能因缓存的 800 元上限误挡，或因并发漏算预留越过 1200 元。旧 config 保持可重新打开，
不要求调用者用 1200 元伪造一个新的原始 config。

700 元实际已结算告警与支出加持有的 exposure 告警均保持。已结算费用低于 cap 也可能因
在途保守预留而无法继续派发；必须等待在途收口或按冻结恢复安排处理，不临时缩小预留。
新 UNKNOWN 的守恒/授权处置也核对有效上限，但不改变已存在 UNKNOWN 的原记录。

## 必要 CPU 控制

新增 `tests/test_finance_v9_monetary_amendment.py`：13 项控制全部使用临时 SQLite，
没有真实 API、GPU 或付费钱包写入，覆盖：

- 800→1200 只追加元数据和事件；旧请求、计数器、config、分区、UNKNOWN 原样保留。
- 同一记录幂等；不同追加身份拒绝。
- 追加前已打开的实例实时采用有效 cap；八线程并发预留可跨原 800，不能跨新 1200。
- 700 元告警不变；只持有而未结算的金额不冒充实际费用。
- pending、未知、halt、已有生产调用或账本不守恒时拒绝首次登记。
- 未授权、未接受风险、错误 config、其他 cap、其他前检和事件缺失时 fail closed。
- 不创建缺失钱包；原 config 可以正常重新打开追加后的同一钱包。

这些是预算边界工程证据，不是全量审阅完成保证、材料有效性或 VTDO 效果证据。
