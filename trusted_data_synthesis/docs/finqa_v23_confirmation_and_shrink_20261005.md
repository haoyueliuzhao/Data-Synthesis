### 新登记的统计方法

主指标为 Full−Static 的原生执行准确率。每道 test 题先对三个**固定训练 seed**的配对差取平均，再对全部1,147题等权平均；程序准确率列为描述性次指标，三个 seed 的原始差值及胜／负／平始终报告。

对原始来源簇进行20,000次配对 bootstrap：

- 来源簇按原标识字典序固定排列。每次有放回抽取与原簇数相同的簇索引。
- 同一个簇的重复权重同时作用于所有六个模型，不对 Full／Static 或各 seed 独立重采样。
- 每次统计量是“被抽簇中逐题配对差之和”除以“被抽簇的题数之和”，保持任务等权目标，不改为公司等权。
- RNG 固定为 NumPy PCG64，seed20261005，记录 NumPy 版本；95% percentile 区间采用0.025与0.975分位，插值方法固定为 linear。
- 只有主指标区间下端严格大于0，才称为这六个固定模型下的正向确认。区间跨0不称为确认或等效；不追加 seed、题目或更换候选直到显著。程序指标不额外计算确认区间或 p 值。

来源簇 bootstrap 刻画的是固定六模型条件下的任务来源不确定性，不覆盖所有训练随机性。原 test 未用于本轮反馈和模型选择，不代表报告来源绝对独立或没有预训练曝光。即使 Full−Static 得到确认，也不能据此声称 Full 优于 C-only。

## 实验 B 等先验距离的 N 控制

### 唯一新增分布

每个 seed 使用原 C-only step596 的真实参数、Adam、RNG、材料和已存外层反馈。qC 与 qN 分别取原同点实验中关闭和开启 N 的更新分布；这里的 qN 模型是局部 N 对照，不是主线最终 Full。

构造 `qγ(z|x) ∝ qC(z|x)^(1−γ) r(z|x)^γ`，一个 seed 只有一个全局 γ，且 γ 在[0,1]。只根据已有分布，令任务权重 μ 下的 `KL(qγ || r)` 与 `KL(qN || r)` 相等。μ 使用原支持清单中的显式权重，不从成绩推测。

令 a＝1−γ，沿该几何插值的 KL 对 a 的导数为 `a × Var_q(log(qC/r))`，非负。因此目标必须位于0与 `KL(qC || r)`之间。求解使用固定80轮二分、绝对匹配误差上限1e-12，端点按原分布处理；不试训、不使用准确率或 NLL 选 γ，不搜索多个 N 系数。

若任一原 seed 的目标不可匹配，整个 B 分支登记不适用，保留三个 seed 的判定；不删 seed、不外推 γ、不临时改指标。A 是独立登记的确认研究，不因这个纯分布适用性判定改变模型选择。

### 训练和评价

每个新增分支独立恢复原 C-only step596，只替换为已固定的 qγ，训练149步至745。原 `outer_done`、材料顺序和任务日程保留，区间内不触发新的700条反馈，不重算 C，不改变 Loss。采用独立模型／优化器／RNG进程，不把 qγ 接在 C reverse 模型之后。

三个新增模型各在同一 calibration120 上使用原两次随机生成和一次greedy，共1,080条。原 C-only／N 对照共2,160条既有评分在 checkpoint、登记、配置、题目坐标和封存身份一致时直接复用，不重新生成。

本补充协议将 **greedy 执行准确率**明确列为部署目标，两次随机生成的期望表现另报；旧机制的混合360条主结果不回写。报告 qγ−C-only、N−qγ、N−C-only 的分 seed 配对差及均值，不新增显著性主张，不挑有利 seed。calibration120 已曝光，这依旧是机制研究，而非独立确认。

这个控制只匹配一个全局先验 KL，不匹配逐题 KL、熵、到当前分布锚点的距离、梯度范数或训练结果。登记并报告 q/r、欠分配状态的概率质量回补、TV、逐题KL、熵、质量集中度等差异。这里的“质量”首先指训练概率质量；χ0／χ1只是已有过程标签分层，不等于金融真值，也不是 N 的输入。

## 对 N 尺度解释的修订

原 N 定义为 `N=[log(r/π)]_+`，其映射为 `0.05+0.9(1−exp(−N))`。它进入 logit 的系数为 `0.2/(4+1)=0.04`。令 `y=log(π/r)`，在冻结平滑后的 C 及其尺度、忽略公共归一化项的局部分析中，相关坐标项为：

`0.8y + 0.04 log[0.05 + 0.9(1−exp(−[−y]_+))]`。

当 y 从负侧接近0，N 项的直接斜率修正趋近 −0.72，合并后约为0.08；另一侧该局部斜率约为0.8。**这不是完整归一化系统的特征值，更不是 Student 闭环收敛率。**状态归一化耦合、C、RMS和模型均会变化。

该计算说明不能仅凭 N 指数0.2就称它“很弱”。它与“回先验可能削弱部分有用重分配”的假设相容，尚未定位原因。实际每遍仍消费相同原包，N 不创造新的任务或独立轨迹；熵升高不等于新增行为覆盖。本次不改 ε、N 指数、温度、C 估计器、Loss或任务，先进行等距离控制。

`JFull−JC = (vFull−vC)×aC + vFull×(aFull−aC)`，即 `−4.30351076 pp = −4.60897937 pp + 0.30546861 pp`。

两个模型的可执行子集不同，**这只是描述性恒等式，不是因果分解**。不能说 Full 的金融推理更强只是格式差，也不能说 N 导致全部提交退化。
