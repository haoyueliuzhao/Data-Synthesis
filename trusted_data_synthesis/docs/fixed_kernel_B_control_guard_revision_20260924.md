## 3. 阻断原因及“等值”的精确定义

原入口为 [fixed_kernel_B_training_worker_20260922.py](../scripts/fixed_kernel_B_training_worker_20260922.py) 的 `_distribution`。它在已核对外层身份、前缀绑定、数值门和完整支持集后，直接执行控制分布字典比较：

```python
pi[task] == binding["prior"][task]
```

材料先验允许以分数字符串保存概率，例如 `"2/5"`。原冻结分布数值核会将其转为数值；已经保存的外层更新使用浮点表示，例如 `0.4`。Python 字典比较要求对应值直接相等，而字符串 `"2/5"` 与浮点数 `0.4` 不相等，因此即使控制任务没有发生数值变化，也会触发：

```text
B_training.control_prior_unchanged
```

在本次恢复授权前，对已存在的 seed11 外层结果进行核对，**80 个控制任务在原数值核 `_scalar` 的转换语义下逐状态全部严格相同**。这里的比较依据是已经冻结、原实际分布更新也使用的解析规则，而不是另引入一种概率精度约定。

原解析函数位于 [finance_qa_vnext_anchored_vtdo/distribution.py](../src/trusted_synthesis/experiments/finance_qa_vnext_anchored_vtdo/distribution.py)，其核心规则是：字符串经 `Fraction` 后转换为浮点数，其他允许值按原 `float` 路径转换，并拒绝布尔值及非有限数。该原函数本身不修改。本修订只在最终控制先验不变检查时，对两侧使用这一相同函数，再要求每个对应状态的转换结果严格 `==`。

这不意味着宣称二进制浮点 `0.4` 是有理数 `2/5` 的无限精度表示。所主张的等价性限定于**本实验原冻结数值核实际使用的标量表示**。任何经过该原转换后仍不同的控制概率都必须被拒绝，即便差异很小，也不因“接近”而放行。

本次不采用 `isclose`，不添加绝对或相对容差，不舍入、不 clipping、不重新归一化、不重算先验，也不重新写入 `pi_next`。非控制任务的更新分布亦不变。

## 4. 新准入模块的最小行为差异

新增 [fixed_kernel_B_control_guard_20260924.py](../scripts/fixed_kernel_B_control_guard_20260924.py) 承载修订后的尾段分布准入。它保留原 `_distribution` 的全部既有检查，只替换上一节所述的控制概率比较语义：

1. 非 Delayed-C 条件仍返回原 B 先验的深拷贝，不触发贡献更新。
2. Delayed-C 仍要求外层报告绑定同一原协议、job key、共同前缀 checkpoint SHA、optimizer snapshot ID 和分布更新 ID。
3. 外层 `numeric_guard_passed` 必须为真；已有 `numeric_guard.json` 仍须通过。
4. 全部任务及逐任务状态支持必须与原 B 先验完全一致，不能仅检查控制任务或跳过支持集检查。
5. 对控制任务全部对应状态，按原 `_scalar` 解析两侧并严格比较；任何不等、非法标量或解析失败都停止。
6. 准入返回原已保存的 `pi_next`，不创建另一套训练分布，不写回或“修复”旧工件。

因此，本次修订允许通过的新增情况仅是：原外层身份、数值门及支持集均合法，控制概率在原数值核中相同，但存储类型或文字表示不同。它不将“控制先验不变”从要求改为建议，也不把旧失败记录改为成功。
