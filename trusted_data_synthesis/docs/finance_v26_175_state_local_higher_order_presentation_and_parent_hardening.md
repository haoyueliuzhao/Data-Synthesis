## State-Local Presentation Contract

### Reference-independent source ordering

v26.174 first moved the reference Choice to normalized source slot zero. v26.175 removes that
operation. Each State orders source Choices by:

```text
canonical public Operation bytes
then source Choice handle
```

The reference handle remains a frozen Host design parent but does not define source slot zero.
The formal Schedule Catalog records `reference_first_source_normalization_count=0`.

### Pre-outcome State-local schedule

One exact Schedule is derived for every:

```text
v26.171 source Package artifact x target Component
```

The derivation seed binds the Schedule Contract, source Package artifact, Component, canonical
source Choice order, reference handle, public argument-field order, fixed salt, and an explicit
collision nonce. It reads no model outcome. The Schedule identity is a direct parent of the new
Development Package and zero-Prompt Runner Input Package.

There are exactly 80 Schedules and 80 distinct materialized rank codebooks. Cross-State codebook
reuse is zero. Each two- or three-Choice Schedule contains six Replica rows and gives every source
Choice every latent rank exactly `6 / Choice count` times.

### Latent-rank factorization

Every model-visible rank channel receives its own State-local rank relabeling:

```text
Candidate position
action-ID lexical rank
Legend position
display-handle lexical rank
value-handle lexical rank for every public argument field
```

All channel values are deterministic functions of one balanced State-local latent rank. This is
intentional: any fixed function of the registered rank channels selects a fixed latent-rank class,
and the reference occupies each class only at the structural baseline. Channel relabelings and
Replica order vary by State, so the v26.174 global joint codebook is not reused.

This factorization is a structural control over the registered rank surface. It is not a claim
that every possible model-visible textual or semantic feature is independent of the reference.
