## 5. 新数量语义与格式指标

新政策为 `public_quantity_interpretation.v1`，仅用于本轮。
共享公开合同明确这三题的目标美元金额为 USD，不做币种兑换；
相关原来源均为美元符号金额。这个币种说明是新 Γ 中公开的共同任务约定，
不是从私有参考数值反推模型想说的币种。

分别记录自动数量判定、结合实际 Final 语义后的 `V_quantity`、
`V_format` 和完整轨迹资格。规范格式不是完整轨迹的额外硬门槛。

| 对象 | 预定规则 |
| --- | --- |
| V_format | 仅检查实际 final 对象存在可支持的数值 value，且 unit 字面恰为 USD_million |
| V_quantity | 根据实际 Final 发布的数值、量纲、币种与明确尺度解释物理量，再与目标比较；结合 Final 期间／方向／内部一致性评审 |
| 完整轨迹 | 数量通过，公式／来源／单位／发布关系通过，真实成功计算先于 Final 且实际支撑该 Final |
| 正确数字＋显式错误币种或尺度 | FAIL，不能靠参考数值救回 |
| 币种或尺度无法解释 | UNDETERMINED，不默认填 USD 或题目尺度 |
| 没有 Final | 不从先前 message／工具输出拼接答案，完整资格不成立 |

单位解析采用冻结的有限组合语法：币种代码／名称／符号，单个 thousand/million/billion
及复数尺度词，和 in/of 等连接词；比例与百分比分别处理。
不是把后来观察到的字符串加入白名单。
`$ in millions` 可以在唯一公开币种上下文下解释；`million(s)` 只显式给出尺度，
必须公开目标币种集合和相关来源币种集合一致且各只有一个元素，才补全币种。
显式 Final.currency、可解析的币种声明和 Final 内部单位冲突不能被上下文覆盖。
错误币种、元与百万元、比例与百分比都保留各自错误或未定状态。

实际 Final.value 若存在，直接解析，不拿参考值替换；缺少 unit 时仅可由同一实际 Final
里与该数值唯一对应的明确金额表达补足。
若没有 value 字段，实际 Final 文本本身具有唯一明确金额／单位表达，也可解释为数量；
但 V_format 不因此变为 PASS。文本有多个可能答案、字段冲突或解析域外表达时保留未定／失败。
所有解释均记录提取位置、原字段和原文，不改写实际响应。

支持的有限数值域：不超过 256 字符的十进制／分数字符串，支持规范千分位与科学计数，
科学指数绝对值不超过 18，拒绝布尔值及非有限数。
数值转为目标尺度后应用原数值容差原则：
分数为精确比较；十进制按发布分辨率折算，容差上限为 0.005 目标单位，
下限为 1e−12 目标单位。单位尺度转换不等于偷偷扩大容差。

自动解释不能替代完整财务语义审阅。
Final 的方向、所述期间、其他数量字段及来源关系若冲突或未定，仍影响最终 V_quantity／轨迹资格。
合法但含错误的先前计算可以通过真实后续修订形成有效终局，但实质修订必须进入完整类。
工具输出与 Final 一致性单独比较物理量，不先要求它等于参考值才记录执行一致。

本轮只执行新规则的有限本地正反例与新 N/E 工作流控制，不重跑旧控制全集，不另做模型单位校准。

## 6. 从公开关系到完整类的分层测量

每题每条件原始分母固定为 8，至少分别报告：

| 层 | 证据边界 |
| --- | --- |
| 公开提及 R | 模型公开文本或实际请求表达式明确给出相关明细关系；泛泛说“考虑明细”不够，E 的宿主指令也不是模型证据 |
| R 操作数被消费 | 诊断记录成功调用中实际使用的登记明细来源操作数；附带但未被表达式使用的变量不计 |
| 确认执行登记 R | 成功 calculate 的实际来源符号标准形与登记 R 关系及活动来源一致 |
| 来源与充分关系成立 | 每个已执行 R 调用分别检查金额、角色、期间、单位及关系的公开证据 |
| R 实际支撑 Final | 真实 R 结果在所选答案依赖链中，或属于已验证的独立核验；与实际 Final 数量和公开链接证据一致 |
| 完整行为 | 纯 D、纯 R、实质修订、独立核验及其他有效完整类分别保留 |

消费明细操作数不等于算对明细关系；相同数值不等于实际使用了同一来源；
中间执行过 R 也不等于 Final 使用它。保留该诊断可以解释部分执行尝试，而不冒充纯 R 产率。

两个主产率分别为：
`a_exec_R(x,g)＝已确认实际执行登记 R 的会话数／8`；
`a_valid_R(x,g)＝完整有效且完整签名匹配登记纯 R 的会话数／8`。
前者可包含后来未到 Final、来源语义错误、实质修订或双路核验的会话；不能替代后者。
来源／符号映射未定不会反向改写原数量或财务资格，也不重归一化有效质量。

完整签名保留：固定生成条件、任务版本、来源文档、目标范围、实际答案来源符号标准形、
活动支持、实质修订路径和已执行独立核验。
登记纯 D/R 都要求空实质修订路径及空独立核验列表。
修改输入域、成功算错后改用另一来源、真实第二依据核验，均不会被当作格式噪声抹去。
格式修复可以消去格式差异，但实际错误请求与后续历史仍保留。
无法完整映射的有效轨迹保留未定质量，不另造一种“未定类”。

N/E 类 ID 必须含各自条件身份；只在同一任务、同一条件内作完整有效会话配对。
跨条件的 `E−N` 产率差只作固定样本的描述，不冒称提供商随机性配对、稳定概率差、
Student 效用或理论 Contribution。
