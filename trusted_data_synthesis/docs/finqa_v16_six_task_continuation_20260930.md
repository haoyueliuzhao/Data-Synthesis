## 单次模型判断和 Host 职责

新请求固定 **deepseek-flash**，每题最多一次，共六次，无模型回退、容量重试或失败追加请求。新协议发请求前同时检查显式 model 和原钱包模型；返回 envelope 也核对模型名。沿用原明确代理路线与 TLS 验证，HTTP transport retries 为 0，read timeout 为 1200 秒。

输入含每题全部原始公开 unit、source／row／column、动作、真实动作观察关系和最新失败返回。原 source 与全部轨迹不截断，不用 SFT 正目标 mask 裁去上下文。最新失败只是待裁定对象，不能作为语义事实默认继承。每份输出 cap 固定 8192，不以旧输出长度不足为理由扩大容量。

模型只输出以下内容：

- `states`：每类 `members`、区分及 χ 的 `basis`、`chi`、必要原 unit `evidence`，以及实际 `changes`。
- `resolution`：解释如何解决最新失败和原备注；若备注只是与分区一致的说明，需明确说明，而不是删除旧原件。
- `unresolved`：若仍存在真实分歧，必须写明；非空就不准入。

Host 确认每个原包恰好一次出现于分区，生成稳定状态 ID，解析已提供原 unit 的确切位置，并由原 action 自动关联其实际 observation。χ1 的每个成员必须有 observation 之后同一包的模型公开内容或 action arguments 作为 consequence；工具结果不能代替 consequence，不能用一个成员的证据推广全类。χ0 不自动填入，members 不从“剩余集合”推算，也不凭字段存在证明语义真实。

这种输出去除了重复成员表、命题图、partial quote 和模型生成的长 ID；它没有降低完整包集合、逐成员来源或实质修改要求。模型和人工判断、Host 机械派生分别具名，原始模型字符串和检查首因都保留。

六份请求零 API 构建的实测 wire bytes 依任务顺序为 65895／43296／65830／73437／62849／74324，原 unit 数为 242／157／239／309／233／278；字节计数不是 Token 预测。正式 preparation 的 ID 为 `be6d472ea7a904501c5cefcd61f60d56bfb8e318f19f31e923017686b8d201ea`。

## 十五条尾段的调度和真实外层

原五臂为 Static、Manual+、Manual−、C-only、Full；Full 仍是唯一主候选。继续原 Qwen2.5-7B-Instruct、全层 q/v LoRA、seed11／29／47、AdamW、Full 监督与固定均匀包核。外层点为 298／596／894／1192，机制点为 447／745，1490 为唯一最终点。Manual− 不替代 C 反方向控制。

新增独立臂入口只接受已经迁移的真实 shared step298，使十五条尾段可以按照实际空闲 GPU 排队，而不必每个 seed 先串行跑完三个非自动臂。固定调度先 C-only，再 Full，后 Static、Manual+、Manual−；这只改变排队顺序，不改变每条臂内部任务顺序、RNG、学习日程或评价候选。每个臂有独立锁和反馈目录，GPU 使用 UUID 排他锁，原 run-seed 入口的排他 seed 锁与独立臂共享锁互斥。

首次正式 outer 同时承担真实验收，不另外采“验证版”700 条再重采。保留原完整类 G、非空 Adam 虚拟点、350 题 × 2 的固定 700 条 Agent 反馈及完整 logP 反传。公开推理、工具动作、观察后的更新、修订、Final 和 EOS 均属生成概率；工具观察是条件输入。全零反馈保持 π，不补采；缺失、数值或资源故障保留为失败而不是 Q0。

本次不预记 C-only／Full 的共享节省；两者各自正式执行。若以后考虑额外共享，必须另有真实同参数、Adam、π、RNG、日程和反馈身份依据，不能仅凭 N 初值或奖励计数一致。

实际类 G 采用 eval 模式，现有模型在此模式不启用训练用梯度 checkpoint，因此 SFT 的显存峰值不能作为 outer 的上界。GPU 24576 MiB 空闲门槛仍只是启发式，正式 outer 未通过之前不声称其真实 CUDA 验收完成。另将完整训练 driver 恢复时的 `torch.load` 定点改为 CPU 加载，再由 optimizer 恢复状态到参数设备，保持非 capturable Adam step 与 RNG 的 CPU 语义，与已验收 prefix 的恢复方法一致。

主矩阵总物理训练基数仍为 `3×298 + 15×1192 = 18774`；共同前缀不是额外训练。反方向和同点 N 机制按原登记单列。
