## 单次模型判断和 Host 职责

新请求固定 **deepseek-flash**，每题最多一次，共六次，无模型回退、容量重试或失败追加请求。新协议发请求前同时检查显式 model 和原钱包模型；返回 envelope 也核对模型名。沿用原明确代理路线与 TLS 验证，HTTP transport retries 为 0，read timeout 为 1200 秒。

输入含每题全部原始公开 unit、source／row／column、动作、真实动作观察关系和最新失败返回。原 source 与全部轨迹不截断，不用 SFT 正目标 mask 裁去上下文。最新失败只是待裁定对象，不能作为语义事实默认继承。每份输出 cap 固定 8192，不以旧输出长度不足为理由扩大容量。

模型只输出以下内容：

- `states`：每类 `members`、区分及 χ 的 `basis`、`chi`、必要原 unit `evidence`，以及实际 `changes`。
- `resolution`：解释如何解决最新失败和原备注；若备注只是与分区一致的说明，需明确说明，而不是删除旧原件。
- `unresolved`：若仍存在真实分歧，必须写明；非空就不准入。

Host 确认每个原包恰好一次出现于分区，生成稳定状态 ID，解析已提供原 unit 的确切位置，并由原 action 自动关联其实际 observation。χ1 的每个成员必须有 observation 之后同一包的模型公开内容或 action arguments 作为 consequence；工具结果不能代替 consequence，不能用一个成员的证据推广全类。χ0 不自动填入，members 不从“剩余集合”推算，也不凭字段存在证明语义真实。

这种输出去除了重复成员表、命题图、partial quote 和模型生成的长 ID；它没有降低完整包集合、逐成员来源或实质修改要求。模型和人工判断、Host 机械派生分别具名，原始模型字符串和检查首因都保留。
