## 2. 冻结有限关系：三种视图不互相冒充

每条有效会话同时保留：

1. 完整原始公开序列，包括每个模型原响应、计算请求、工具结果、接口错误及 Final。
2. 计算前或同次请求的模型原话，以及分离的离线任务关系、角色、期间、单位解释。
3. 实际执行表达式、消费的变量值、来源元数据、工具结果及 Final 所用计算。

新表示不构造旧 Action—Update 对或 State，不恢复在线 Formula/accept 门槛。
完整公式的一次调用就是实际记录的一次调用；无执行的草稿不是工具结果。
公开关系的证据来自真实计算前／同次模型响应，不把事后数学归约写成模型原话。

来源关联采用明确的逐 AST 出现位置账本。每项绑定保留原文数值跨度、原段落与表格上下文、
模型响应全文和摘要、原语义评审 ID、实际消费数值。
来源 ID 在模型请求中明确提供时标为 `model_declaration`；
根据角色／年度／单位公开文字作出的离线对应标为 `reviewer_interpretation`。
后者不是按相等数字自动搜索，也不是模型当时发布过 source ID。
命名变量的数值被计算器消费，不等于附带的来源元数据被计算器认证。
所有角色与期间注释均为离线解释；它们不会注入监督输入或目标。

有限归约域为有证据绑定的有理数算术 `+ - * / sum avg`，包括有依据的单位常量。
变量改名、空白、JSON 字段顺序、同一来源的等价代数表达不单独造类。
零贡献项可退出活跃支持，但所有来源、原表达式和原 DAG 保留。
涉及来源因子的约分、消除原定义域约束、未支持算子或未绑定出现位置均为未定。
不同来源身份不会因数值相同而合并；不展开财务恒等式，把期末期初差与滚动明细、
全球披露与区域重建、公司现金流直取与 CFO/capex 建立保留为可能不同的实际依据。
这些替代路线仅用于局部规则控制，不代表本批模型真的采用过。

行为键包含条件、任务版本、来源文档、目标范围、活跃来源支持、
答案连接的来源符号有理式和实质公开修订路径。没有要求每题出现两个类。
同结果不允许抹掉有意义的公式、来源配对、目标或期间修订。
本次有限账本覆盖既有有效会话中的单次真实答案计算；
两条格式恢复由已审阅的前后全文 SHA 严格锁定，原文与错误反馈仍完整保留。
未登记的多调用语义、普通公开语义历史或不明修订返回 `UNDETERMINED`。
通用算术归约器有真实 result-reference 展开的合成控制，但本批未测试真实跨结果规划，
也未实现一般自然语言修订识别。

### 7.5 本轮结论与下一步边界

本轮已经实例化“既有开放轨迹 → 有限行为关系 → 原样监督整包”。
主要观察是 **同公式、同实际支持的重复实例**，不是需要用更长路线或更细协议标签补出的多样性。
没有依据在这五个单点经验分布上声称已经形成有意义的类概率干预；
也没有实现原六任务各 1/6 的训练分布。

下一次若采集新材料，应优先选择确有替代充分依据、且公开目标明确的任务；
这只是后续建议，本轮没有启动新采样、选择 N3 新版本或执行训练。
有限映射与 token 适配成功均不证明稳定行为多样性、复杂自主规划、Student 效用或 VTDO 效果。
