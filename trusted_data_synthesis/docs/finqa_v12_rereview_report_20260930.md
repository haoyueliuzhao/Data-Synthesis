## 三、方法与执行协议

### 3.1 完整原文、短 ID 与层间解耦

审阅输入保留原问题、来源、公开解释、工具请求、真实观察及历史顺序。主机将原始字符串映射为可追溯的短 unit ID，提供实际 action/event ID；原文不截断、不改写、不删除早期错误历史，不向审阅模型发送原生私参或答案。

A 判断四项关键过程检查，并给出唯一的正向监督选择；B 只判断过程，不生成另一套 mask。两侧上下文隔离，但使用的是同一模型，不能将其当作统计独立的专家样本。

四项检查为：`evidence_and_operations`、`observation_interpretation`、`unwithdrawn_critical_contradictions`、`actual_revisions`。选择已有 ID 或唯一精确原文片段，只能机械定位证据；定位成功不自动证明金融推理、上下文限定和模型结论正确。

结果分四层保存：原始 JSON／声明、关键过程证据绑定、A 监督投影、新流水线候选门。过程证据不足仍为 unknown，有据的关键错误仍为 invalid；监督字段失败不再抹掉可以独立读取的过程结果。原始坏 JSON 不补全、不猜引用、不通过普通解码器覆盖重复键恢复 valid。

付费前修正了两个具体接口问题并保留负控：一是 A 整个监督字段缺失不能被误列为核心 envelope 失败；二是 outer 投影不可用时，内层机械展开的正向字符数不能冒充有效监督。pair 中 `offline_A_reason_projection` 原样保留，有效 `A_reason_projection` 的未知计数用 `null`，不是 0。
