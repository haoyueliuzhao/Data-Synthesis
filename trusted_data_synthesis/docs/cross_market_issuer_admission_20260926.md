# 跨市场校准：法定发行人身份与冻结项目历史对照

## 范围与证据

本阶段只读取已经保存的 440 份官方 PDF 逐页原文 JSON，及本地原有 SEC submissions 身份 JSON。后者仅补充原项目 100 个 CIK 的法定名称、历史名称、注册司法区与地址，不是新财务来源，不重新访问 SEC，不增加 PDF 处理、模型或 GPU 预算。

冻结前人工审阅了原文公司名称、报告抬头、上市代码与更名线索。名称清单是这些材料的转录，不是通过模型生成的新名称。程序在逐份原文中复核每个声明。此过程未读取任何新模型 Q，不声称在财务数值或名称读取之前盲定规则。

`cross_market_issuer_admission_20260926.py` 在提交冻结、登记后运行，登记绑定自身及原基础脚本 hash、原固定名单、440 个原文文件、历史来源名单和对应本地历史身份快照。恢复只复用相同协议的不可变完成件，不修改旧解析/原文核验预算。

## 身份与跨上市规则

每份报告至少同时满足：

1. CNInfo 的“公司中文名称／法定中文名称／编制单位”，或 HKEX 的审计报告股东收件人、已经审阅的公司自身报告抬头，出现精确法定全称。文中提及客户、供应商或子公司不通过这一条件。
2. 保存报告自身股票代码字段及定位。代码只作为法定名称到原来源证券的证据，不作为 issuer cluster ID；报告缺少可验证字段时，该文档保留但不准入。
3. 名称发生变更的证券，必须在同批原文找到明确新旧名称连续性声明。不能只因代码未变就直接把不同法定名称串联。

issuer ID 为规范化法定全称的 SHA256（`issuer:` 前缀）；不是 CIK，也不携带证券代码。保留所有文档级拒绝原因。证券有部分报告无法绑定，不会把其他已证实报告一并伪装成全部通过，最终面板必须逐题核对具体原始文档的 admitted 标记。

为避免中文／英文名称不相等掩盖 A/H 关系，额外读取 CNInfo 自报外文全称字段，与 HKEX 自报法定名称比较；不会自行翻译或按集团品牌模糊合并。记录每份自身上市代码字段的原文、完整宽度代码和对其他冻结证券的命中提示。别名碰撞或另一候选证券出现在自身上市代码字段，保留为待裁定，不自动拆分为独立簇。代码窗口只提供明确字段的定位，不把全文数字作为发行人关系，也不宣称这些窗口穷尽全球所有上市关系。

法律主体相同与公司集团相关不是同一件事。上市母公司、子公司及联营公司可能相关；因此 64 个法律发行人映射即使完成，也不能称为 64 个经济独立随机样本。历史例子如 CK Hutchison、CK Infrastructure、Power Assets，以及 Henderson 与 Towngas 的关联，不能仅凭不同股票代码忽略，但也不能把不同法定主体误合并成一个报告发行人。

## 项目历史与未知曝光

既有历史名单包括 100 个项目来源 CIK。本地 submissions 为这些 CIK 提供原始当前名称、formerNames、tickers 和注册/业务地址。程序保留各快照引用，不只比对较旧规范名称。CNInfo 的外文全称必须来自原报告字段，不把中文名称与英文历史名单的字符串不相等视为有效双语对照。

输出严格区分：

- `admitted`：法律发行人及所引用文档的身份映射是否成立。
- `project_source_identity_screen_passed`：相对于冻结项目来源的双语当前／历史名称筛查是否完成并无匹配；不是全世界或全模型曝光的证明。
- `archived_registry_matches`：已确认的当前／历史法定名称碰撞。
- `no_exposure_certified=False`、`base_model_pretraining=UNKNOWN`：不声称基础模型未看过这些公司或年报。

即使字符串没有命中，注册司法区、业务地址与公司自己声明的身份材料仍原样保留供实质裁定；这些辅助事实不会被自动概括成“绝对未曝光”。需要严格的项目发行人历史裁定时应引用这些身份材料，而不能只引用零名称命中计数。

## 核验与未完成项

8 项纯 CPU 合成测试覆盖：自身身份字段与正文提及区分、审计报告收件人、股票代码的数字边界、外文名称换行、编号标签截断、明确更名连续性及真实名称 hash。Ruff 通过。

保存原文预检查找到四起更名明确证据；目前 Towngas 2025 报告未定位到自身股票代码，西安饮食报告未提取到自报外文全称。前者文档绑定不通过；后者法律发行人映射可成立，但跨语言项目历史筛查保留不完整，不能悄悄用自己翻译的英文名称补齐。最终计数以登记运行后的不可变 `issuer_admission_01/admission.json` 为准。

本阶段不等于财务准入，不生成金标准，不构建或评价 180 题，不授予任何生成／评分预算。后续面板编译仍需逐题绑定发行人、原文文档和财务事实合同。
