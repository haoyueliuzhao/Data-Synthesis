## 新算法的固定设计

后继为独立 `J_sources` anchored 研究，不是救活人工plus/minus。保持当前200训练
任务、mu=1/200、两池原材料及train/sealed角色、Full监督、10epochs/400updates、
Qwen2.5-7B和已有v2公开来源视图；不加Probe、工具训练、HierLoss或新提示/预算。

A三条件：Static alpha0、C-only anchored、Full anchored，各种子11/29/47；Full
是事前唯一主候选，C-only更好也不能代替Full。B和720题确认不在当前执行准入中。
若Static的材料、质量、调度、初始化、配置及单卡执行条件确实匹配，则单独登记
复用旧三份alpha0及其已有开发评分的证据；未核对前复用信用为0，不按同名计信用。

每个自适应运行在epoch0、5使用当前模型与真实AdamW状态计算一次全总体虚拟步，
每轮180题×2条随机完整轨迹=360，temperature1/top_p1/top_k0，32响应/32工具、
2,048新token、24,576上下文。随机seed含pool、training seed、round、TaskID、
repeat，不含condition；不得因失败重抽。全部360条完成封存后独立评分。

logP必须包含每条实际采样token及结束EOS，工具文本只作条件，不用SFT正响应mask，
不除长度；固定分母1/360。反馈梯度只用于虚拟一步pullback，不直接更新真实Student。
完整360条奖励全零正式登记`UNINFORMATIVE_FEEDBACK`，该轮pi不变并继续固定内层
安排，不加样本/奖励/NLL替代。若Novelty未激活，明确报告，不能判定Novelty无用。

冻结epsilon=.05（正值势下限，不是概率下限）、a=.8、b=.2（C-only仅b=0）、
lambda_current=4、lambda_prior=1；同独立分支的RMS尺度与N温度规则。两次更新
只是预算安排，不是收敛证明；唯一最终checkpoint是epoch10，不按成绩选中间点。

新状态先验必须恢复原alpha0包质量：目标任务pi0(z|x)=0.5*n(x,z)/n(x,method)，
控制任务保持静态，r=pi0。每目标token系数为pi(z|x)/(5*n(x,z)*L_package)，完整
消费现有全部合格原包，不再乘pi，不强求64包，也不改变已冻结原包顺序或监督域。
