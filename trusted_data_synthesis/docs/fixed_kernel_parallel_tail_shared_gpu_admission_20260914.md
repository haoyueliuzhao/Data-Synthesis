## 显存门槛的依据与限制

2026-09-14 本次修订时，现有同模型训练进程的 GPU 显存占用约为
23,804–25,894 MiB，即约 23.2–25.3 GiB。新后端仍是每卡一份相同 BF16
基础模型及 FP32 LoRA，每个 rank 顺序处理分配到的轨迹，不将八份模型堆在同一卡。
因此先采用 32 GiB 门槛，较当时最高观察占用多 6,874 MiB（约 6.7 GiB），
为通信缓冲、分配器及波动保留余量。这是依据现有运行数据作出的工程估算，
不是额外 Student 试训结果，也不是完整生命周期显存峰值上界证明。

其他用户作业启动后，已有训练的短窗口 token 归一化耗时增加约 11%–19%。
这个观测不能当作新八卡后端的加速比实测；共享计算资源会使运行时间继续波动。
本次不承诺固定完工时间、独占吞吐或避免一切显存不足异常。

`nvidia-smi` 空闲显存快照不是资源预留。检查通过后，其他进程仍可能继续申请显存，
因此存在准入之后的资源竞争风险。若实际训练失败，应保留真实失败和部分产物，
不自动伪造成功、不重跑已完成训练。本次不操作其他用户的进程。
