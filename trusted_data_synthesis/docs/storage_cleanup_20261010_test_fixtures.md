## 删除前保护与备份校验

固定计划绑定一次性脚本摘要及每个目标目录的完整成员元数据摘要。目标必须是约定父目录下的精确非符号链接目录；路径祖先不允许重定向，跨文件系统、特殊文件、普通文件硬链接均不纳入清理。测试符号链接的解析目标均限定在 `test_tmp/` 内，归档保留链接本身，不读取链接目标作为额外文件。所有目标均未被Git跟踪。

删除前检查本账户可见进程的工作目录、命令参数、打开文件、内存映射及与临时路径相关的少量环境变量；最终检查覆盖25个可读进程，没有目标占用命中。另有4个明确识别的systemd、PAM或sshd进程受权限限制，其他账户进程未作全面审计；不将该检查表述为全系统零占用证明。

普通文件备份时计算内容SHA256，完整归档关闭后重新读取全部97,367个成员，核对成员顺序、路径、类型、文件长度和内容SHA256，以及符号链接目标。压缩文件、成员清单、备份校验凭证和目录项先持久化，再逐目录重新验证原成员元数据并移除源目录。未通过校验的对象不会进入删除步骤。

执行前审查修正了两项保护：备份凭证发布时同步其目录项；仅当全部移除及最终保护检查均通过，才记录 `COMPLETE`，异常须记录失败。首次计划和脚本原样保留为 `prior_plan_01.json`、`prior_cleanup_01.py`，该旧计划没有执行过；修订后重新生成并绑定计划，不回写旧证据。
