# 固定材料核、同接口给定公开来源的训练价值实验

## 1. 新授权及效用范围

用户在第三份后继审计后明确要求“参照审计继续实验”。本次依据完整 395 行文本，
SHA-256 `d82b24afd0d6eedbf7aa6b58b3d32982dc2010c344a8902eb6fee1a451c2bf2c`，
先建立公开来源视图，再在输入与新运行时准入通过后，运行 **10 模型 × 180 开发题
= 1,800 个会话，上限 57,600 次生成**。审计链接中的另份长报告和 ZIP 未作为
本地已经取得、复跑的证据；他方 20 项算术核对不记作本轮执行。

本轮效用是 `J_sources`：在给定固定公开来源后，模型从空工具结果表起步，
自行选择依据、读取、计算和交付的完整财务资格。它不等同 `J_snapshot`，
不是覆盖旧 R0、预算 pilot 或 R1 完整快照结果，也不是延长已见历史单步续接。

旧 R1 60 会话、60 单步及其限定结论保持原样。不再修改 R1 说明或提高预算，
不自动补评其余 1,593 个 R1 会话。原200训练任务、7,076包和九个已训练检查点
全部复用，不新增 Probe、梯度训练、Loss、LoRA、学习率、训练步数或轨迹。

## 2. 公开来源编译规则：在任何本轮模型输出前固定

采用原开发 panel 中已经公开的 `native_annual_records` 文档。这些记录在
任务枚举前按来源、指标域、tag优先级及申报时序规则选定，不是私有见证叶子列表。
编译函数只接收原公开题面/合同和此公开文档，不接收私有答案、参考程序、
方法标签、模型成绩或某臂输出。

统一窗口规则：

- 下界为原公开各期间的最早 start（若无 start 用 end）减一天；上界为所有
  公开期间的最大 end，边界均包含。
- 保留原公开年度记录中 end 落在该窗口内的**全部指标记录**。
- 不按题目指标、操作、数值大小、端点/movement或某方法是否成功过滤。
- 所有原选定版本规则继承已冻结来源域，不以数值闭合或预期答案另选版本。
- 原始标签、定义、单位、记录、源 SHA、URL和原生指针保留。
- 新 source_id 仅由原 raw_object_id 与 native_pointer 的哈希机械生成，
  不编码金额、年份、方法或见证角色。原 graph_ready 标志和 opaque fact ID
  不作为模型指引提供；窗口内原数值记录不删减。

原问题文本、数量合同、实际期间及全部候选期间原样保留。原问题已有的操作合同
不是本轮新增公式提示。不给 Probe 历史、已执行的读数、已算结果、所选峰值期，
不把私有见证程序变成公开输入。

新输出独立为 `artifacts/qa_vnext_fixed_kernel_value/given_sources_value_20260915/`。
每题保留 canonical TaskID，新增 source-view manifest、surface id、public SHA、
runtime binding 与在线/重放身份。任何新视图都不得冒用旧 public SHA。

## 3. 运行合同与完整财务标准

`read_source(source_id, unit)` 对齐原训练的 JSON record 读取调用形式；机械映射
仅把 source_id 解析为已声明的原始记录/指针，不纠错、不补事实、不猜概念。
实际读取由原训练工具解析值和转换单位，同时保留原快照评分器需要的 raw object、
pointer、record、concept、actual_period与支持来源。原 `calculate` 原样复用。

三期均值和峰值后查询保留原目标。`select_max / compare / lookup_selected` 原工具
及完整候选期间证明要求继续提供并评分；它们仍可能存在额外结构迁移，不删掉
`other_financial` 组来制造成功率。系统说明采用训练读取/计算说明，加原已注册
选择工具说明，不增加新 Gamma_doc 候选，不按输出迭代提示。

每会话从公开任务起点、空工具表开始，32 响应 / 32 工具，每响应 2,048 新 token，
上下文 24,576、greedy、neutral、原 BF16/FP32 LoRA/Flash SDPA 不变。不强制
Final，不自动重试、续写或补答案。在线执行与离线重放使用同一新来源适配。

金融资格继续要求正确首个 Final 及真实来源、单位、实际期间、完整计算/选择
支持；不因来源由系统提供而免去这些判断。诊断指标不代替主效用。

## 4. 一次新输入准入，不能依据模型结果挑选

新视图先逐题写入不可覆盖文件并冻结公开 manifest；之后离线检查器才读取原
开发 bundle 的声明支持，核查所需原生依据均保留，不反向改变公开视图。
检查覆盖固定180题、每组三类各60；没有三题挑选 pilot。

只进行新版本需要的必要核验：来源文件/指针/原始字节，方法中立窗口规则，
200训练任务与180开发任务及来源簇不重叠，完整候选支持保留，单次 tokenizer
构造下180份初始输入长度，以及新执行/重放接线。不重扫旧会话，不重做三包mask
或全训练材料检查，不打开720题确认内容。

完整原始窗口超长、来源不充分或规则无法建立时，按原固定题记录问题；不删题、
换简单题或按答案裁剪。输入合同未通过时，不启动1,800模型会话。

## 5. 固定比较、资源与停止

模型为原三臂×三种子九检查点，加同一未经本次微调的基座；基座不是alpha0，
也不是第四个训练种子。开发题未进入Student梯度训练，但已被研究者用于开发和
诊断，不能称为全新盲测。

`J_sources` 为三个组各60题的完整资格率等权平均。分别报告：

- SFT效应：三种子alpha0平均减基座。
- 分布增量：plus、minus各自三种子平均减alpha0；同题同种子配对。

失败、UNKNOWN、无Final留在固定分母，同时分类报告；来源选择、读取、计算、
Final及实际方法作为诊断，不临时加权总分、不事后删除地板/天花板题。
只有完整A开发的平均配对主效用严格为正才移动，平局依序alpha0、plus、minus。
原 `A_minus_47` 的8卡训练后端和数值归约lineage继续披露，不伪称物理执行相同。

GPU并行按可用显存准入，不要求利用率为0，不操作他人作业。R1实测reserved
峰值约26.586—52.678 GiB，高于旧24GiB估算；新准入拟采用至少60GiB剩余，
单卡一个本轮worker，并记录实际峰值。精确调度及矩阵清单在输入通过后冻结。

本次只授权开发比较。即使出现正方向，也不自动训练B或运行确认；相关6次B训练、
8,640确认会话仅属未来条件方案。本轮不启动HierLoss或anchored更新。无正方向
则保存结果，不再改来源包或挑指标直到正向。

代码及详细实验说明按用户授权提交并普通推送指定main；实际产物仅发布精确
白名单的小型规则/准入/计划/汇总，原始来源、模型和会话留本地。

## 6. 实际输入构建与无损布局修订

第一版180题已经一次构建完成，来源充分性与训练任务/来源簇隔离全部通过。
只读取12份原始公开快照，共58,181,998 bytes；200训练任务来自14个来源簇，
180开发题来自另外12个来源簇。原训练包、旧会话和确认内容读取均为0。
三项新CPU编译/读取/重放控制一次通过（1.83秒），未运行任何Student。

第一版初始长度6,486—22,375 token，虽均能容纳单次2,048 token生成，但6题
历史增长余量低于4,096，最少只有153。这是多轮消费风险，不能只凭“第一轮能
装入”即开始支付1,800会话预算。第一版及其作用域限定的通过收据原样保留。

在没有任何本轮模型输出的情况下，统一建立v2无损布局：重复原始文档URL/SHA/
类别仅存一次，重复概念标签/定义按concept共享一次；每条原生record、pointer、
unit、source_id与顺序全部不变。展开每份v2必须精确等于v1公开对象，运行时仅
机械还原读取需要的元数据。SYSTEM文字完全不变，不另加提示，不删数值材料。

v2只读取已构建的180份公开视图及旧准入收据，不再打开原始快照、私有bundle或
训练材料；对改变后的输入必须重新计数长度，最低预留4,096历史增长token。
一个新无损/执行/重放控制一次通过（1.83秒），没有重复原三项控制。真实模型
矩阵只允许使用新的v2 manifest，不能与第一版输入混算。
