## 1. 原始总体、分工与泄漏边界

保留原始 FinQA split 与已有角色规划：SFT 1000、feedback 350、calibration 120、train reserve 4781、dev 883、test 1147。不根据旧 Probe 产率选择旧 165 题；本轮原始总体是 1000 题。官方 split 不等于报告/公司完全隔离，不能以 split 名称声称消除了来源重合。

初始 Probe 只接收原题及原始公开表格/文本，不接收作者程序、私有答案、目标状态、其他槽位答案或其他模型审阅。8 个槽位独立完整运行，不投票、不 Best-of-N、不按 NLL/C/长度/稀有度选优。每题 8 槽都进入共同材料候选，不保留旧 6+2 方案。

仅当全部 8000 槽生成完成、原始请求/响应与同一账本完全结算关联、generation seal 封存后，才打开私有参考做原生评分与审阅。参考文件全字节哈希验证，但只有这 1000 个 SFT 参考对象进入审阅；不是声称私有文件任何其他字节都未被读取。

## 2. 公开轨迹和薄工具接口

新版本：`bigfinance-derived-vtdo-v6` / `finqa-public-reasoning-v1`。每次响应一个原生工具调用，允许有简短公开 R/U/Q 解释：证据或推导摘要、上次观察如何改变判断/动作、尚未解决的问题。R/U/Q 只是可读提示，不是强制格式语法，不要求制造错误或增加核验步骤，不索取隐藏内部推理。

可用工具仅 `list_sources`、`read_source`、`run_program(program)`、`submit_program(program)`。程序执行器只接收 PublicTask 与原公开表格，不读取金标准。`submit_program` 只提交原程序文本，不执行答案校验，也不要求单独答案/scale。新独立原生评分入口与旧 answer+program 入口隔离，避免把 `final_answer=None` 误当成正常程序提交失败。

完整公开内容、原始工具参数、真实观察、错误和恢复历史保存。无法解析的原生调用作为只读 `unparsed_tool_call` 原件保存，不改写成成功动作。工具输入、输出和会话上下文由 CPU 重放校核；这不是第二次模型执行。原始 API 请求和返回字节、实际用量与账本关联，不把离线 Student 重编码伪称 API 采样 TokenReceipt。

## 3. Experiment 0：固定采集、双审阅、共同资格

### 3.1 采集配置

- 1000×8=8000 会话；启动顺序为 slot index 优先，然后原始任务顺序。
- Flash，thinking disabled，temperature=1、top_p=1，不发送 seed；每响应最大 2048 token、每会话最多 32 次调用；API 输入预留上界 1,048,576 token。
- 16 会话并行。第一个登记槽串行检查实际输送与结算，不是额外 pilot、质量筛选或提示搜索。
- 网络重试、隐藏继续、内容修复、失败补采全部为 0。正常错误/无工具/步数耗尽属于原槽结果；网络/未知账单等基础设施问题保存并停发。

### 3.2 双审阅的执行单位

每道题的 8 条封存原轨迹组成一个审阅包，固定两个隔离上下文，各审一次整个包；因此每条轨迹仍有两次判定，共 **2000 个审阅请求**，不是 16000 次逐槽请求，也没有第三次对齐调用。共享的原公开证据在每个包内只保存一份同定位原文；生成阶段绝不看到这个包。

两审均 Flash、thinking disabled、temperature=0、top_p=1、JSON object、单响应上限 16384、8 并发。两审不可看到彼此输出。相同模型的两次上下文不是统计独立审阅，更不是数学证明或算法效果证据。

固定 rubric 要求关键断言、假设、撤回、行动与观察后的判断变化；所有证据引用原文 Unicode `[start,end)` 跨度，主机不代写语义结论。公开推理及动作参数需覆盖 approved/retracted/unknown 监督标记。每个任务同时提供 28 对轨迹语义关系，避免第三次模型对齐。

存在事前明确风险：很长的 8 轨迹包可能无法在 16384 输出上限内给出全部引文、监督标记和关系。截断、缺字段、非法引用、两审分歧按 unknown 保存，不提高输出上限、不拆包补审、不事后更换 rubric。预算不是获得完整有效核的保证。

人工核查包取事前任务顺序前 10 题的固定槽位，生成原件和双审判定待核查材料。所有结果标记 `human_reviewed=false`；没有假称人工完成，也未私自增加全量人工签字门槛。

### 3.3 三个量与正向材料

分别保留 `Q_native`（原生 execution 正确性）、`V_trace`（有限过程判定）、Mapper（有效行为分类）。原生正确不证明推理正确；过程一致但答案错误也不能作为正确正向 SFT 包。

共同材料资格为 **Q_native=True 且 V_trace=valid**。Q=False/unknown 的记录保留独立过程结论及排除原因，不改写成另一种失败。对全部共同合格原包进行整体语义对齐：任一个合格原包无法归类，该题 Mapper incomplete；不能删除难归类包，再对剩下易归类包重归一。invalid/unknown 从不强行充当正向监督。

状态是证据—命题—推导—行动—观察更新关系的规范图，而不是原文或工具顺序哈希。别名、重复等价节点、独立读取顺序与表述长度不制造新状态；算术运算与有意义的操作数顺序必须保留。相同工具顺序若证据取舍、实质核验或修订不同，可以有不同状态，但要有原件证据。

粗投影 χ=1 仅当实质核验/语义修订有证据，且影响命题接受、证据选择、程序或提交；纯格式修复、重复执行、更多工具调用或自称“已核验”不计为 1。χ=0 不意味质量低，χ=1 不意味价值高。

### 3.4 经验核与报告

对任务 x，保留全部共同合格且整体已映射原包。`K(P|x,z)=1/n_xz`，`r(z|x)=pi0=n_xz/n_x`；这是有限经验实现，不是真实 Probe 条件概率估计。

报告原 8000 分母、Q/V/共同资格分别的比例、每题每状态包数、单例、经验条件熵（自然对数）、已观测状态数、`D_pi_obs=sum(|Z_x|-1)`、`M_flex=sum 1{|Z_x|>1}/1000`。未覆盖完整 1000 题时总体 D_pi 为 null，不把缺题记零损失，不报告虚构状态全集覆盖率。任一题无合格包/映射不完整/监督 mask 不可用，会阻止原 1000 题训练准入。

## 4. 联合预算与恢复

价格来自当日保留的官方 HTML，链接：<https://api-docs.deepseek.com/zh-cn/quick_start/pricing/>。按每百万 token 的人民币高峰价输入缓存命中0.04、未命中2、输出8计算所有时段保守上界，不冒充实际发票；低峰可能更低。

同一 SQLite WAL 账本 purpose=`finqa_v6_generation_and_semantic_review_v1`。生成上限2048与审阅上限16384按每次真实请求分别预留：约2.113536元/生成请求、2.228224元/审阅请求。该预留使用最坏输入上界，不是预计每次收费。真实 usage 的 hit/miss/output 完整校核后释放未用预留。已结算花费＋全部在途/未知预留不得超过800元，达到700元警示；硬请求上限为8000×32+2000=258000。

请求先持久 reserve 和 dispatched，再发 HTTP。断网/未知响应/不完整用量保留预留并停止全库新增请求；正常语义 JSON 不合规是有账单的审阅 unknown，不混成网络失败。所有真实调用使用同一 key，但日志不保存 key。

恢复时只读关联全部槽位、审阅原始 body、精确调用坐标、真实 usage、费用和原子计数。原账本缺失、未完成原槽、未知调用、孤立结算或修改的原始内容均不得自动重发。可以续跑尚未启动的登记槽，但不能重新生成已经发送的槽/审阅。800元不足时报告未完成，并等待明确新授权；不会通过新建数据库归零。

## 5. Student 编码与所有训练臂的共同接口

真实原始 Qwen2.5-7B-Instruct tokenizer/chat template 对已审阅原包离线编码。保持完整失败、撤回和后续观察上下文；仅完全落入双方认可原文跨度的 token、认可且执行成功的原生动作、对应 Student EOS 进入正向目标。工具观察、系统、用户、padding 无目标；错误、撤回和未知部分 mask0。这些离线 ID 不是 API 采样凭据。

## 7. Experiment 4 实际结果与边界

见 `finqa_v6_experiment4_math_20260928.md`。固定正势的归一化log-odds映射收缩；固定平滑C与RMS、N(pi)变化时，在本参数下 `.2*.2*.9/.05=.72 <= .8` 可证明振幅距离最多.8收缩。证明使用归一化log差跨零、标量单调性和完备log-odds空间，不能只凭普通逐坐标Lipschitz省略论证。

纯CPU256组合成概率对最大数值比0.8000000000000003（浮点舍入），160步两起点距离约8.88e-16；仅合成核验，不取代数学证明。首次正更新比值上界19^.16≈1.60177<2，镜像2r−q+严格正无需clip；反向仅TV对称，通常KL/熵不对称。全零反馈保持分布的恒等分支不能称.8收缩。

这些结论不延伸到动态C、变化RMS、Student、Adam、采样和整个训练闭环。新增实际API、模型推理、GPU调用均0。原始记录在 `experiment4_01/{record.json,manifest.json}`。
