## 用户指令与偏移纠正

2026-09-27，用户明确指示：“本次实验继续，后续实验 api 调用模型固定为 deepseek-flash，你此次发生了偏移”。本轮来源辅助审核引入了 `deepseek-v4-pro`；这是执行方模型选择的偏移，不应把资源使用授权、排障或“继续实验”理解为可自行改变模型范围。

从本指令起，后续新实验的所有API阶段固定 `deepseek-flash`，不只限于Student相关生成：材料处理、来源审核、疑点裁定、格式恢复、小试及其他辅助任务同样适用。不因HTTP429、响应错误、质量判断或“独立审阅”自动回退或升级到另一模型。确需变更时先说明影响并取得明确授权，不能事后将既成实现当作用户设计依据。

新实验代码须显式写出模型名并在HTTP之前校验；实验协议、请求原文和执行凭据须保留实际模型身份。历史代码中的其他模型名属于历史或本轮冻结记录，不是后续实验默认值。
