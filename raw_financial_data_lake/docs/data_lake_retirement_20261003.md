## 恢复限制和历史影响

`fin_raw/` 主要是已下载的 PDF、SEC filing HTML/TXT 和结构化 JSON，并非重复压缩包。数据库主要保存文件的 `storage_uri`，不是原文件的二进制备份。删除后旧记录可能指向不存在的文件。本次不修改或删除数据库记录，不宣称旧数据湖的查询和重提取功能仍完整可用。

`kg_archive/` 和 `qa_archive/` 是 Parquet/ZSTD 冷归档。旧保留流程会在归档核验后清除数据库中的历史版本，因此这些文件可能是唯一的历史恢复副本。删除它们和导出文件，会失去相应历史 KG/QA 版本的本地恢复能力。

旧 `finance_qa_vnext_task_build/archive.py` 固定引用的 `kg_build_id=kg_20260723_191638_396e6b92` 归档也在清理范围内；相应旧工作流不能再直接重放。旧 README 中的生产命令保留为代码使用说明，不应被理解为本机原始材料仍然齐备。

未来如需重建旧数据湖，必须重新准备原文、处理失效的数据库文件引用，再重新抽取和构建。没有验证全部远端 URL 当前可下载，也不能保证重新下载得到完全相同的历史内容。审计记录、文件计数和本说明都不是数据备份。
